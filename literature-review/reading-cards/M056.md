# M056 — ABM特征提取与参照构造

## 1. 书目、版本与阅读范围
Siamak Khatami、Christopher Konstantin Frantz，From Concepts to Model: Automating Feature Extraction of Agent-Based Models Using Large Language Models，JASSS28(3)9，2025-06-30，DOI10.18564/jasss.5734。[正式HTML](https://www.jasss.org/28/3/9.html)§2–4及附录入口定向阅读；Figure3/8已取得并目视。未取得PDF、代码或逐项追读四个案例原论文。

## 2. 研究问题与贡献
将ABM概念文档中的用途、主体、环境、模型层变量/行为提取为JSON，供模型交流及未来自动代码生成。对象是研究者的建模辅助流程，不是运行时LLM社会主体；core_method / empirical_method_test / controlled_comparison。

## 3. 资料与实验单位
四个文档Poverty、Tiger、Trout、Elites；两份ODD及两份概念说明同时涉及不同模型/领域，不能将组间差异归因为ODD格式效果。九类提示覆盖用途、主体、环境和模型级特征；每个报告的LLM/ABM/prompt重复10次。

## 4. 提示与参照构造
§2.27用重复回答中最常见的结果作presumed correct answer，并抽样人工核查；§3.2用Poverty与GPT-4o迭代提示至至少一次正确。它不是独立盲态标注、完整覆盖的人工金标准，调参文档与最终评价之间存在共享。

## 5. 评价操作与结果
§2.37以all-MiniLM-L6-v2嵌入后的cosine similarity均值/方差评价；Figure8展示相似度，不是提取准确率或precision。重复一致与预期答案语义接近，需要与事实正确性分别检验。环境提示P5–P7受源文档辅助信息影响，不能将笼统模型优劣外推至所有题目。

## 6. 人工审计与独立性
§4.8称抽查10%生成与预期输出以检查相似度机制；精确抽样分母、评分者数量、盲态、一致性和独立完整gold均待核。10次回答也不是10个独立模型或10个独立文档。

## 7. 模型身份与报告差异
§2.25写ChatGPT-4.5-turbo，§3.4写4-turbo；Figure3/方法写3个commercial而§4.2写4个。Figure8可见12个模型标签（含GPT-4o），与文字10个LLM的计数口径未闭合。保留差异，不自行修正型号或相乘推算实际总运行预算。

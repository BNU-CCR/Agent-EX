# ReliMap精读：个体准确与群体分布不能互代

2026-11-28，ED。取得EMNLP2026正式18页PDF，读正文和方法附录、p11末风险说明，参考未逐项追溯；p7/8/17目视。见[卡片](../reading-cards/M176.md)、[获取清单](../batches/method_round2/ed_relimap/acquisition_manifest.json)和[核查记录](../batches/method_round2/ed_relimap/reading_checks.json)。正式题录仅出版月，PDF会期不改成首次在线日，M176仍candidate/date_pending。

ReliMap把基础分布、个体资料条件化和人口聚合分层，分别看ACC与TVD。其有用贡献是展示不同层级评价会分歧，而非证明一套通用社会模拟流程已可靠。

| 需要区分的事项 | 已读证据 | 结论范围 |
|---|---|---|
| 个体与群体 | 表4中18/69增量比较的ACC/TVD同号 | ACC提高可伴群体TVD变差；不是所有模型/任务的26%失效率 |
| 参照人群 | 完整profile过滤，未用调查权重 | R2对保留分析人群，不对全国或原始调查总体 |
| 真人帖与标签 | Media真实帖经GPT4o分类，20例人工检查 | 真实来源与测量正确性分开，不认证全150项金标准 |
| 重复与波动 | 五属性/人口抽样seed；图10±1SD属性抽样 | 不是生成随机性CI、五独立社会系统或seed数量建议 |
| 覆盖与偏差 | c100下增加N，同分析池真人子抽样作基线 | 局部稳定不证明规模可消除条件预测偏差 |
| 理论上界 | 三角不等式和组件收敛条件 | 充分条件，不是必要性、独立性或因果机制证明 |

表4的23行×三模型已逐项抽为[69比较表](../batches/method_round2/ed_relimap/table4_incremental_comparisons.csv)，18同号、一个零∆ACC不计反向，18/69≈26.09%。数值是相对百分比改变，不是百分点。此处只复核报告表与算术，不重跑模型或推断显著性。

存在三项应保留的具体边界。第一，ASPG用真实标签估计单属性信息，不能当已验证的部署策略或联合信息量；Religion的相关改善均值反而为−.0299。第二，表2写Religion76属性、表7/图写80，未静默统一。第三，表5的Neither欠预测从−13.74到−12.39改善，与正文“进一步欠预测”不一致；附录G跨指标只支持总体方向，表10的若干相邻步骤仍反向，例如GPT4.1 c80→100的TVD改善而KL/EMD变差。

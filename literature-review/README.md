# Agent-EX 文献梳理与投稿期刊定位

本目录用于持续维护 Agent-EX 的社会模拟、多智能体互动及相关研究文献，并形成核心文献来源期刊与投稿候选期刊名单。

## 当前范围

- 时间：**2022 年 1 月 1 日至每次实际检索截止日**。
- 学科：先系统检索新闻传播相关 SSCI、CSSCI 期刊，再沿研究问题扩展到社会模拟、计算社会科学、计算机、计算语言学、信息科学与信息管理等领域。
- 主线：信息接触、社会影响、私人意见与公开表达、群体意见演化，以及互动机制与模型自身倾向的关系。
- 期刊索引类型、会议与预印本状态分别记录；2022 年以前文献不安排专门检索或精读。

## 执行入口

请整体复制 [CODEX_TASK_2022_ONWARD.md](CODEX_TASK_2022_ONWARD.md) 给 Codex，或让 Codex 直接读取该文件并执行。任务书包含项目资料入口、时间规则、筛选标准、检索流程、字段、阅读卡、投稿评估与验收要求。

阶段顺序：项目定位与试检索、新闻传播逐刊检索、跨学科扩展与精读、投稿判断与交付。试检索完成后按任务书直接继续，不设置重复方案审批。

1. [项目定位](protocol/project_context.md)：当前六格研究、已有结果与解释边界。

4. [文献与期刊工作簿](exports/literature_and_journals.xlsx)：梳理进度、文献、期刊、来源、投稿、日志和会议。
5. [进度与接续](progress.md)、[检索缺口](reports/coverage_and_gaps.md)。

最重要的定位调整：已有研究已讨论无互动基线、网络极化与互动/模型偏向分解。Agent-EX应具体论证固定网络比较、匹配无feed基线、实际接触记录和私人/公开状态分层的增量，不能声称首次网络模拟或已经识别心理认同与迎合机制。

任务书中的种子是前期发现的检索线索，实际入库时须核验日期、版本和内容；本目录初始化不表示已经完成系统文献检索。

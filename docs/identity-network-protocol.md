# Paper 1: identity-network study protocol

Status: approved direction, preliminary implementation.
Study ID: `paper1.identity-network.v1`.
Spec: `superpowers/specs/2026-10-01-identity-network-2x3-design.md`.

The main study is group identity salience 2 × network structure 3. Six cells use
the same demographic persona and recent-private-update memory rule. Explicit
consistency is off. Both A conditions retain identical backend groups; only
membership visibility differs. Publication remains externally scheduled.

Private state is the primary state layer; public stock, flow and expression gap
remain recorded. A final primary metric and estimand are not selected here.

Legacy I×C×E protocols/results retain their original meanings at
`legacy-2x2x3-2026-10-01`. Historical persona pilots motivate the study but do not
validate the minimal-group manipulation.

Stages: local preparation → bounded identity check → six-cell dynamics pilot →
formal freeze → formal runs. A label null result is preserved. Only the separately
bound, predefined neutral framing stage may follow; there is no prompt search.

Formal config retains `UNRESOLVED[SIS_FORMAL_N]`, `UNRESOLVED[SIS_FORMAL_T]`,
`UNRESOLVED[SIS_FORMAL_SEEDS]`, `UNRESOLVED[SIS_PRIMARY_OUTCOME]` and
`UNRESOLVED[SIS_PRIMARY_INFERENCE]`. Explicit candidate values for memory/feed,
graphs, model settings and manipulation sizes/criteria precede preliminary runs.

## 1. 研究对象

Paper 1 研究的不是 AI Agent 注入真人社交网络后的真实社会效果，也不以关系拓扑变化为首要因变量。研究对象是：

> 在一个由 LLM-agent 构成、具有异质初始立场的在线讨论网络中，Agent 经历多轮局部信息暴露、理由生成和立场更新后，群体意见分布将形成何种稳定形态。

“Agent 进入在线舆论场”是现实问题背景；实验所能直接支持的是 LLM-agent 模拟网络中的生成式意见动力学。

## 2. 核心研究问题

> 在异质初始立场的 LLM-agent 讨论网络中，多轮局部互动会使意见分布走向整体均质化、单向端点集中、极化，还是“组内均质化—组间差异化”？Persona 条件化如何改变这一演化路径？

三个子问题：

1. 相对于无社会暴露，多轮邻居暴露是否改变群体意见分布及理由多样性？
2. 身份信息和身份连续性要求是否分别改变 Agent 的可影响性与群体演化形态？
3. 局部网络暴露产生的结果，是否不同于接收相同数量但打乱来源的社会信息？

## 3. 理论主张

Paper 1 不预设 LLM-agent 必然均质化或必然极化，而是比较四类可区分的演化形态：

- 整体均质化：总体分布收缩为较集中的单峰；
- 单向端点集中：均值显著漂向一端，端点质量增加；
- 极化：中间位置减少，彼此分离的立场区域获得更多质量；
- 双层结构：预注册初始立场组内部差异下降，同时组间距离维持或增加。

核心理论判断是：

> 多峰或多极分布不自动等于更高的意见多样性；它可能同时伴随组内表达模板化、中间立场流失和跨组可影响性下降。

## 4. 概念边界与非目标

### 4.1 Paper 1 包含

- LLM-agent 的异质初始立场、初始理由和身份信息；
- 固定讨论网络上的局部暴露；
- 多轮异质加权随机顺序意见更新；
- persona 条件化和社会暴露的可识别比较；
- 立场分布、组内/组间结构和文本理由多样性分析。

### 4.2 Paper 1 主实验不包含

- RLHF、instruct/abliterated 或 safety alignment 对比；
- 真人—AI 混合网络和真实历史行为回放；
- 关注、取关、关系重连或推荐算法内生变化；
- 多模型、多语言和大规模议题全因子矩阵；
- 跳过小规模校准而直接启动 N=1000；
- 将 pilot 中 weak/medium/lifelong 复合 prompt 直接当作正式自变量。

上述内容分别进入 Paper 2、外部效度研究或稳健性扩展。

## 5. 实验结构

### 5.1 因素 A：身份信息

- `identity_absent`：不提供人口学或经历背景；
- `identity_present`：提供人口学和议题相关经历，但不写入方向性长期立场，不规定必须保持当前意见。

### 5.2 因素 B：身份连续性要求

- `continuity_absent`：仅要求根据自身判断和所见信息更新；
- `continuity_present`：要求当前回答与自身先前立场、理由和历史发言保持解释连贯，但明确允许在有说服力的信息下改变意见。

身份信息与连续性要求采用 2×2 正交设计。正式论文不再把四个 cell 简化称为线性的“persona 强度”，除非 Phase 0 证明其 manipulation check 呈现预期单调关系。

因素 B 只能增删上述连续性指令，不得引用或增删人口学、经历和其他身份材料。所有 cell 都具有初始立场、初始理由和历史发言，因此 `identity_absent × continuity_present` 具有明确且相同的连续性对象。

所有条件禁止加入：固定方向的政治/价值立场、抗从众命令、最大变化幅度限制和“永不改变”等锁定语句。

### 5.3 因素 C：社会暴露

- `self_history_only`：只接收自身历史，不接收其他 Agent 信息；
- `shuffled_social`：从逐节点保持WS度数的固定shadow graph邻居接收有限未读公开帖；
- `ws_neighbors`：从固定WS网络一阶邻居接收有限未读公开帖。

该三水平设计依次识别重复生成/自我记忆、一般社会信息暴露和局部网络结构的增量作用。

`shuffled_social`使用如下固定关系算法：

1. 每个matched seed从WS边表派生一张逐节点保持度数的shadow graph；它全程固定，只依赖seed和拓扑，不读取实验结果；
2. 禁止自环、重边和真实WS邻边，并要求全连通；不可满足时在运行前失败；
3. 每个cell只读取本cell公开帖，不跨条件复制内容；
4. 每次激活读取该关系图邻居自游标后的最新至多B条新公开帖，过量旧帖过期、不回填已读帖；
5. 保存shadow graph、游标、候选/入选exposure和呈现槽位；
6. 不事后强制匹配立场分数或文本分布。两种社会系统因反馈而产生的内容差异属于处理效应的一部分。

社会消息数量匹配只适用于 `shuffled_social` 与 `ws_neighbors`。`self_history_only` 是“无社会信息”的总效应基线，天然具有较少的信息量；不将它解释为纯拓扑效应，也不使用无关填充文本伪造等长输入。

### 5.4 主矩阵

主矩阵为：

`2（身份信息）× 2（连续性要求）× 3（社会暴露）= 12 cells`

同一 replicate seed 下，12 个 cell 必须共享：

- 初始 Agent 人口与身份材料；
- 初始立场和初始理由；
- WS 网络；
- Agent注意/表达参数以及完整激活与发布日程；
- WS图、固定shadow graph、feed容量和记忆窗口制品；
- 模型版本和生成参数。

差异只能来自协议规定的实验因素。

## 6. Agent、网络与更新规则

### 6.1 Agent 初始状态

每个 Agent 至少包含：

- `agent_id`；
- 人口学/经历材料；
- 初始立场；
- 初始理由；
- 预注册初始立场组；
- 历史发言和实际 exposure 记录。

人口材料与初始立场原则上应平衡或独立生成，避免身份文本直接泄露预设立场。

### 6.2 预注册群体

“组内—组间”分析以实验开始前的初始立场分层为主要群体定义，不使用终态聚类反向定义群体。具体量表和切点由 Phase 0 protocol freeze 确定，并满足：

- 切点在查看正式结果前固定；
- 每组具有足够样本；
- 跨条件完全一致；
- 同时报告连续立场分析，避免结果只依赖离散切点。

这里的“组”是初始意见组，不等同于真实社会身份群体。

### 6.3 网络

- 主网络为固定 Watts–Strogatz 小世界网络；
- 每个 seed 生成一张网络，并在所有条件中复用；
- 正式 Paper 1 主分析不重连边；
- BA 网络只在主效应稳定后作为拓扑稳健性检验。

因此，Paper 1 所称“演化”是网络上意见与理由状态的演化，不是关系拓扑演化。

### 6.4 多轮更新

T=50解释为50个sweeps，每个sweep包含当前N次有放回激活事件。一个run内事件严格串行：

1. 按冻结注意权重和schedule选中一个Agent；
2. 从前一成功事件提交后的公开状态构造有限未读exposure，并读取最近K次成功私人更新；
3. 渲染prompt，生成并解析新的私人立场和理由；
4. 按预生成`publish_flag`决定是否替换其最近公开帖；
5. 原子记录attempt/event并立即提交，再进入下一事件。

失败事件不改变私人状态、公开帖、feed游标或RNG进度；重试与checkpoint恢复必须重放同一event identity。一个run内不得并行提交事件，不同run可并行。

## 7. 结果变量与形态判定

### 7.1 主要结果

唯一 primary outcome 是预注册终点 `T*` 的双层结构变化量：

`S_t = log((B_t + ε) / (W_t + ε))`

`ΔS_T = S_T* - S_0`

其中 `B_t` 为预注册初始立场组的组间方差分量，`W_t` 为加权组内方差，`ε` 是仅为数值稳定而在协议中预先固定的极小常数。较高的 `ΔS_T` 表示组间差异相对组内差异增强。报告该指标时必须同时展示原始 `B_t` 与 `W_t`，防止比值掩盖其中一个分量的退化。

次级结果包括：

1. 总体分布：均值、总体方差、端点比例和中间位置比例的时间轨迹；
2. 双层结构分量：组内方差、组间方差和组间中心距离的时间轨迹；
3. 个体变化：绝对变化量、跨初始立场组迁移率和停滞比例。

探索性结果为文本多样性：预注册理由类别的 Shannon entropy/有效类别数与 embedding 分散度。

不以 Self-BLEU 作为主要多样性证据。

### 7.2 形态判定原则

- 整体均质化：总体方差下降，同时不存在组间距离增加；
- 单向端点集中：端点比例增加且总体均值发生明显方向性漂移；
- 极化：中间比例下降，并伴随两个或更多分离区域的质量/距离增加；
- 双层结构：组内方差下降且组间距离维持或增加；
- 停滞/锁定：个体变化率极低，不能自动解释为极化或多样性保留。

具体阈值、连续轮数和敏感性区间在 Phase 0 中基于 mock 与 pilot calibration 确定，必须在正式实验前冻结。不同形态可以同时出现，分析不强制互斥分类。

### 7.3 主要 estimands

唯一 primary estimand 是 matched-seed 条件下，连续性要求对局部网络效应的调节：

`[ΔS_T(ws, continuity_present) - ΔS_T(shuffled, continuity_present)]`

`- [ΔS_T(ws, continuity_absent) - ΔS_T(shuffled, continuity_absent)]`

该对比在两个 identity 水平上分别估计，并以等权平均作为主检验；identity 的三阶交互作为 secondary。它回答：相对于接收相同数量、但来源随机化的社会消息，身份连续性是否使局部邻居网络更容易产生相对更强的组间分化与组内收缩。

Secondary estimands：

- `ws_neighbors - shuffled_social` 对 `ΔS_T` 的平均效应；
- identity 主效应及其与 continuity、social exposure 的交互；
- `ws_neighbors - self_history_only` 对总体方差、均值漂移和变化率的社会互动总效应；
- primary contrast 对完整 `S_t` 轨迹的稳健性分析。

形态分类和文本多样性均为 secondary/exploratory 解释，不与 primary hypothesis 共同构成一个未排序检验 family。

## 8. 统计设计

- seed/run 是主要独立重复单位，不把 Agent 数量当作重复数；
- 相同 seed 的各条件采用配对/区组比较；
- 轨迹分析包含条件、时间及交互，并处理 run 层随机效应和时间相关性；
- 同时报告效应量、95% CI、完整轨迹和预注册终点；
- 对群体切点、极端/中间阈值和收敛窗口做敏感性分析；
- 若使用多重结果检验，区分 primary、secondary 与 exploratory family 并控制多重比较；
- 未收敛 run 作为右删失或终态未达成处理，不删除后做普通 ANOVA。

## 9. Phase 0 与规模门槛

### 9.1 Phase 0A：构念校准

使用小样本真实模型调用检查：

- identity 操作是否只改变身份信息；
- continuity 操作是否提高历史连贯性，但未造成绝对立场锁死；
- 四个 persona cell 是否存在可解释且非退化的行为差异；
- 量表问题是否只测一个构念；
- 议题是否存在严重单向模型偏置或拒答。

若 continuity 条件导致近乎零变化，必须改写 prompt，不能直接进入正式实验。

### 9.2 Phase 0B：动力学校准

- mock：N=20/100/1000，验证流程、复杂度和指标；
- real model：N=20/50/100，估计变化率、方差、失败率、成本和效应量；
- 使用预先生成的分析 dry run 验证形态判定不会把单向漂移误判为极化。
- 基于 primary estimand 的 matched-seed DiD 对比方差进行功效模拟；不得用单 cell 方差或 Agent-level 样本量代替。

### 9.3 正式规模

Paper 1 采用分级实现，但正式主实验规模固定为 **N=1000、T=50、完整 12-cell 主矩阵**：

1. 构念/流程校准：真实模型 N=20/50/100；
2. 有限规模检验：在 primary contrast 上运行 N=200/500/1000，检查 `ΔS_T`、失败率、吞吐和内存是否随规模稳定；
3. 正式主实验：N=1000、T=50、12 cells，第一阶段每 cell 运行完全相同的 10 个 matched seeds；
4. 在不查看 primary contrast 的均值、方向、置信区间和显著性的前提下，按下述确定性规则进行一次盲态 nuisance-variance 重估；若所需精度不足，扩展至最多 20 个 matched seeds；
5. 正式分析以 N=1000 数据为主，N=200/500 仅用于有限规模诊断和规模敏感性报告。

若每次激活事件调用一次模型，则10 seeds约为：

`1000 × 50 × 12 × 10 = 6,000,000` 次生成；扩展到 20 seeds 约为 12,000,000 次生成。

因此 N=1000 不是单次超大 run，而是带 matched-seed 重复的正式实验。任何资源不足都不得通过只保留一个 seed、把 Agent 当作独立重复或降低完整性标准来解决；应暂停并重新评估模型部署、批处理吞吐或预注册精度目标。

### 9.4 Seed 数盲态重估规则

协议冻结时、查看任何正式结果前，必须确定最小重要效应 `δ_min`。正式主检验使用双侧 `α=0.05`、目标 power `1-β=0.80`。

对第一阶段每个 matched seed `s`，计算与 primary estimand 完全相同的 identity 等权平均 DiD 对比值 `z_s`。重估程序只允许读取中心化残差 `z_s - mean(z)` 以估计标准差，不向研究者输出 `mean(z)`、符号、CI、p 值或任何 cell 均值。

为保留四个 cell 的配对协方差，方差必须直接从 `z_s` 估计，禁止从各 cell 方差拼接。令首批 `n0=10` 个 seed 的样本标准差为 `s_z`，使用预注册的一侧 80% 方差上界：

`σ_U = sqrt((n0 - 1) × s_z² / χ²_(0.20, n0 - 1))`

所需 seed 数按配对单样本主对比的正态近似计算：

`n_req = ceil(((z_0.975 + z_0.80) × σ_U / δ_min)²)`

确定性扩样规则为：

- 若 `n_req ≤ 10`，正式样本固定为10个 matched seeds；
- 若 `10 < n_req ≤ 20`，追加到恰好 `n_req` 个 matched seeds；
- 若 `n_req > 20`，追加到20个并在论文中声明预注册精度目标未满足，不继续用正式结果修改上限；
- 首批10个 seeds 全部纳入最终分析，与追加 seeds 使用相同协议和数据质控；
- 重估只执行一次，追加过程中不得再次查看效应或调整样本量。

`δ_min`、随机 seed 列表、`χ²`/正态分位数实现、取整方式和隐藏输出审计在启动 N=1000 正式实验前写入冻结协议与分析脚本测试。

## 10. 议题与模型边界

- 主实验使用一个主议题和一个固定模型；
- 主议题必须具有清晰单一的态度构念，不能混合事实预测与规范支持；
- 第二议题用于议题稳健性，不与主实验全因子同时展开；
- 第二模型用于模型稳健性，不成为 Paper 1 首轮必需条件；
- 模型、temperature、top-p、system prompt 和输出格式跨主矩阵保持固定。

## 11. 证据边界

Paper 1 可以声称：

- 在指定模型、议题、persona 操作和网络条件下，LLM-agent 多轮互动产生了何种意见形态；
- 身份信息、连续性要求和局部社会暴露如何改变这些形态；
- 表面多峰是否伴随组内与文本层面的多样性压缩。

Paper 1 不可以声称：

- 已证明真实公众会以相同方式变化；
- 已估计真实平台部署 AI Agent 的平均社会效应；
- persona prompt 等同于真实人类身份；
- 固定网络结果证明了关系网络结构发生演化；
- 单向端点集中就是两极化；
- N 更大自动带来更高外部效度。

## 12. 验收标准

研究设计进入正式实现前必须满足：

1. 主问题、唯一 primary estimand、唯一 primary outcome、终点 `T*` 和证据边界写入协议；
2. persona 两个因素的 prompt 差异可自动 diff，且没有额外方向性指令；
3. 两个 social cells 的 exposure 数量、置换约束和来源可审计，且不存在跨 cell 内容泄漏；
4. 预注册群体不依赖终态结果；
5. 形态判定能区分整体均质化、单向集中、极化、双层结构与停滞；
6. Phase 0 manipulation check 排除无效操作和强锁定；
7. matched-seed 分析、完整性校验和分析 dry run 通过；
8. RLHF、真实社交媒体和动态重连未被重新塞回主实验；N=1000 仅按分级门槛进入正式运行。

- 按 epoch 保存 profile、message pool、history 和边表的思路；
- WS 网络数据与旧结果可用于兼容性/迁移验证。

不得直接复用：超长 `utils.py`、全局状态、重复 prompt 函数、超大重试上限、进程池副作用、字符串/整数立场混用和动态重连主循环。关系重连仅保留给后续 Paper。

### 13.3 Pilot-3.0

最值得迁移为正式需求和回归测试：

- `deepcopy`快照可作为不可变证据记录的实现启发，但原统一提交的同步更新语义不得迁移；
- 运行目录、初始 Agent、边表、prompt、exposure、原始响应、解析结果和逐轮状态记录；
- persona 条件矩阵、matched seeds 和 run-level 汇总分析的组织方式；
- 已有 N=20/T=30 结果作为迁移后的行为方向回归检查。

不得直接复用：Notebook 内的正式主循环、20 条角色切片、weak/strong/lifelong 复合 prompt、共享异步 RNG、`top_p` 只记录不传递、缺少 checkpoint/resume、解析失败静默保持旧值和“选择最新 run”但不验证完整性的分析入口。

### 13.4 迁移原则

- 迁移行为契约、测试样例和经过验证的流程，不复制历史技术债；
- 每个被迁移的机制先写成测试，再在新 package 中实现；
- pilot 继续原地冻结，正式代码只存在于 `platform/`；
- Pilot-3.0 行为方向复现是迁移验收，不是 Paper 1 正式结果。

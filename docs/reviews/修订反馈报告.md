# 《从流通阻断到生成置换》论文修订反馈报告

**修订版本**：终审修订版

## 一、针对审稿人意见的逐项修改

### 审稿人意见一：核心研究问题不明确

> **原文**："论文的核心研究问题是什么尚不明确，生成式把关和数字拟态环境的概率重塑是什么逻辑关系？要表达什么？"

**修改措施**：

| 位置 | 修改内容 |
|------|----------|
| 摘要 | 首句改为主动语态："研究据此提出'生成式把关'概念框架，揭示了……"，明确"生成式把关"是本文提出的核心概念 |
| 第 12 段 | 新增三层贡献框架表述："在概念层面，提出'生成式把关'框架……在机制层面，揭示其通过概率地形重塑实现生成置换的微观运作逻辑；在后果层面，阐明这一机制如何导致数字拟态环境的同质化漂移与社会认知系统的演化风险" |
| 全文 | 统一"低熵化"为"同质化"，使因果链更清晰：生成式把关（机制）→ 同质化（后果） |

**修改后效果**：明确了"生成式把关"是解释机制，"数字拟态环境的同质化"是后果，二者是因果关系而非并列关系。

---

### 审稿人意见二：概念拼接、挪用、AI 生成之嫌

> **原文**："论文用了很多炫酷的概念、表述，有些并非新闻传播学科常用的术语……有拼接、挪用甚至 AI 生成之嫌。比如系统性长尾异质观点的生成概率、中位数叙事、无摩擦但低熵、社会表征的方差坍缩、认识论闭合、演化韧性导向、权力解耦（中间件架构）、物理确权（权重开源）等等。"

**修改措施**：

| 原术语 | 修改后 | 位置 |
|--------|--------|------|
| 低熵数字拟态环境 | 高度同质化数字拟态环境 | 摘要 |
| 低熵化重构/漂移 | 同质化重构/漂移 | 第 12 段 |
| 低熵伪境 | 虚假安全环境 | 第 69 段 |
| 中位数叙事 | 主流叙事 | 全文统一 |
| 认识论闭合 | 认知封闭/封闭的认知循环 | 摘要、第 41 段 |
| 演化韧性导向 | 以演化韧性为目标 | 摘要、第 46、71 段 |
| 物理确权（权重开源） | 权重开源（直述） | 全文 |
| 耗散结构 | 开放系统 | 第 45 段标题 |
| 负熵流 | 多样性 | 摘要、第 47、60 段 |
| 简单聚集机制 | 中心化垄断导致同质化 | 摘要、第 63 段 |
| 随机涨落 | 异质性的观点供给 | 第 66 段 |
| 去方差 | 观点多样性压缩 | 第 25、34 段 |
| 异托邦 | 差异化空间 | 第 61 段 |
| 反熵 | 追求变化与突破 | 第 70 段 |
| 4E 认知框架 | 删除术语及四个 E 列举 | 第 35 段 |
| 麦克斯韦妖类比 | 整段删除，改为传播学语言收尾 | 第 26 段 |

**修改后效果**：热力学/物理学/军事学术语已基本清理，全文术语更贴近新闻传播学科规范。

### 审稿人意见三：实然/应然性质混淆，实践场域缺乏说明

> **原文**："作者分析生成式把关的流程、机制等，但到底在哪些实践场域中有应用？缺乏说明。如果仅仅是做一种技术逻辑和技术能力（可能性）的介绍，其学术意义和价值是什么？简言之，作者到底在讨论一个实然问题还是一个应然问题？表述比较含混。"

**修改措施**：

| 位置 | 修改内容 |
|------|----------|
| 第 21 段（新增） | 在第一章第 20 段后新增实践场域说明段落，以教育领域为重点，补充信息获取、内容创作、决策辅助三个场景的简要例证 |
| 第 11 段 | 补充对齐技术族的说明："以 RLHF 为代表的对齐技术族（包括 DPO、Constitutional AI、RLAIF 等）"，明确技术描述的准确性 |
| 第 65 段 | 补充说明："权重开源并非意味着模型没有安全对齐，其价值在于提供了可审计、可修改、可重新训练的可能性"，澄清实然边界 |

**新增实践场域段落原文**：
> "在实践层面，生成式把关的影响已在多个场域中显现。教育领域尤为典型：当学生向 AI 辅导模型提问涉及历史评价、社会争议或伦理困境的开放性问题时，模型往往不会呈现多元视角的争论与张力，而是直接输出经过安全对齐处理的'标准答案'……类似的逻辑也在其他场域中展开：在信息获取场景中……在内容创作场景中……在决策辅助场景中……"

**修改后效果**：实然部分（机制分析+ 场域例证）与应然部分（治理建议）层次分明，实践场域有具体说明。

### 审稿人意见四：术语误用（如认知经济性）

> **原文**："总体来看，本文乱挪用、拼贴的情况比较多。审稿人查阅了一些术语，有些甚至可能就是误用，比如，认知经济性等。"

**修改措施**：

| 位置 | 修改内容 |
|------|----------|
| 第 29、31 段 | "认知经济性"统一替换为"认知省力"，与"认知吝啬鬼"概念统一 |
| 第 23 段 | 修正 RLHF 技术机制描述：改为"经由 RLHF 训练内化于参数权重中的价值偏好会自动生效——它在训练阶段已对……施加了极高的惩罚权重，使其对应的 Logits 数值在推理时被系统性压低"，纠正"奖励模型实时打分"的技术错误 |
| 第 25 段 | 引用修正：Bisbee 等降格为"观点多样性压缩特征"的观察证据，Park 等升格为多样性测量的直接证据；补充多因归因说明 |
| 第 24 段 | 越狱证据弱化为"间接证据"+"概率闸门"比喻，避免逻辑漏洞 |

**修改后效果**：核心术语使用准确，技术机制描述无误，引用与论点匹配。

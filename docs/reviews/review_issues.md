### [F1] Base 模型无法使用 Chat 格式 ✅ 已解决

**问题描述**
Qwen2.5-7B（Base）是纯文本补全模型，不理解 `role: system / user` 的 chat 特殊 token。
当前代码用 `chat.completions.create()` 调用 Base 模型，它会把对话格式当成普通文本续写，输出混乱。

**后果**
对比实际变成"懂对话的模型 vs 不懂对话的模型"，而非"有对齐 vs 无对齐"。
RQ2 的内部效度被直接摧毁。

**决策**: ✅ 采用 **C-abliterated 方案**
- 网络B 改为 `Qwen2.5-7B-Instruct-abliterated`（安全向量切除版）
- 两组均使用相同 chat 格式，消除格式混淆
- 自变量精确孤立为"安全对齐方向向量"的有无
- 实操：优先使用 HuggingFace 社区版；若无合适版本，使用 FailSpy/abliterator 自行生成（约 2-3 小时）

### [F2] 双模型同时运行 VRAM 溢出 → 量化混淆 ✅ 已解决

**问题描述**
Qwen2.5-7B（fp16）≈ 14.5GB，两模型同时运行 ≈ 29GB，超出 RTX 4090 的 24GB。
当前设置 `--gpu-memory-utilization 0.45`（≈10.8GB/模型）会迫使 INT8 量化或动态卸载。

**后果**
量化精度差异本身改变了模型输出分布，引入新的混淆变量：你比较的不只是对齐差异，还包含量化精度差异。

**决策**: ✅ **云端 AutoDL + RTX 4090/4090D，分时运行**
- 平台：AutoDL（autodl.com），按秒计费，¥2-3/小时
- 显卡：RTX 4090 或 4090D（24GB VRAM，fp16 全精度）
- 运行策略：两组实验分时运行（先跑完网络A全部重复 → 再跑网络B），每次只加载一个模型，无需量化
- 模型下载：Qwen2.5-7B-Instruct 走 ModelScope；abliterated 版优先找 HuggingFace 社区版，备选自行运行 abliterator 脚本生成
- 预计总费用：~¥40（含调试）

### [F3] 文本输出 → 数值观点的映射完全未定义 ✅ 已解决

**问题描述**
实验设计中，初始观点为 1-10 分数值，指标也需要计算"方差时序"。
但模型输出的是自然语言文本，方案中从未说明如何将文本转换为数值。

**决策**: ✅ **结构化 Prompt（主指标）+ BGE 嵌入相似度（验证指标）双轨并行**

**主指标：Prompt 末尾强制输出分数**
- 格式：`【评分：X】`（X 为 1-10 整数，1=极端反对，10=极端支持）
- 正则提取数值，每轮计算全体 agent 的方差（多样性）和均值（是否向5漂移）
- 两组使用完全相同 Prompt，消除指令遵循能力差异的干扰

**验证指标：BGE 嵌入语义相似度**
- 模型：`BAAI/bge-large-zh-v1.5`（AutoDL 可直接加载）
- 每轮计算全体 agent 文本输出的平均两两余弦相似度（↑ = 语义趋同）
- 与评分方差趋势对照印证

**可信度验证**
- Spearman 相关检验"自报评分"与"文本嵌入位置"的相关性
- 若 ρ > 0.6，说明自报分数有效，在论文方法论部分专门报告

### [F4] 广播机制歧义：到底广播给谁？ ✅ 已解决

**问题描述**
交互流程写"更新后的观点广播给**所有邻居**"，若误理解为全部 200 个节点，BA 网络拓扑形同虚设，拓扑指标（模块度、社群结构）的意义完全丧失。

**决策**: ✅ **感知与广播范围均严格限定为图结构中的直接邻居节点**
- Agent 每轮只读取其在 BA 网络中直接连接邻居的历史发言
- 更��后的观点也只广播给直接邻居
- BA 网络的 hub-spoke 结构因此真正发挥作用：hub 节点影响范围广，叶节点只受少数邻居影响，信息传播有梯度，拓扑演化有意义

### [M1] 轮内更新顺序未定义：同步 vs 异步 ✅ 已解决

**问题描述**
每轮激活 40 个节点，这 40 个节点更新时：
- **同步**：所有人读取上一轮状态，同时计算新观点（类似 DeGroot 模型）
- **异步**：先更新的节点的新观点可以立即被后续节点看到

**后果**
意见动力学文献证明两种机制产生截然不同的收敛行为。不指定等于结果不可复现。

**决策**: ✅ **采用同步更新**
- 所有激活节点读取上一轮快照 → 并发生成新观点 → 统一写入，进入下一轮
- 与 DeGroot、HK 等意见动力学主流模型对标，审稿人熟悉此框架
- Hub 节点影响力由网络度数决定，而非激活顺序的偶然性，变量更干净
- 完美契合已有 async + Semaphore 架构（所有节点并发读取快照，天然同步）
- 固定随机种子即可完全复现，无需额外控制激活顺序

**记入论文局限性**：异步更新（对应微博/朋友圈实时信息流场景）会产生更快的收敛速度，且激活顺序本身成为影响变量；本研究采用同步机制以保证可复现性和变量控制，未来研究可探索异步机制下的热寂动力学差异。

### [M2] BA 网络关键参数 m 未指定 ✅ 已解决

**问题描述**
Barabási-Albert 模型必须指定参数 m（每个新节点添加的边数）。
N=200 时 m=1（稀疏树）vs m=3（真实社交网络）的度分布和收敛特征差异巨大。

**决策**: ✅ **Phase 0 试点中对 m=2、m=3 做敏感性分析，依结果确定正式实验 m 值**
- Phase 0（20节点）额外跑 m=2 和 m=3 两个版本，对比方差收敛曲线形态
- 若两者趋势一致（仅速度差异）→ 正式实验选收敛更清晰的 m 值，并在方法论中报告敏感性结果
- 若两者结论分歧（定性差异）→ 正式实验需两个 m 值都跑，作为网络结构的调节变量分析
- 正式实验 m 值最终确定后写入 experiment.yaml，需报告网络的平均度、最大度等基本统计量

**参考范围**：真实社交网络平均度约 4-8，对应 m=2（平均度≈4）或 m=3（平均度≈6）

### [M3] Hub 节点的 token 预算危机 ✅ 已解决

**问题描述**
BA 网络中 hub 节点度数可达 20-50+。若 hub 有 42 个邻居，k=5 轮记忆，每条 50 字：
42 × 5 × ~65 tokens ≈ 13,650 tokens，超出 Qwen2.5-7B 约 8K 的有效上下文。
（升级模型量级无法解决此问题，72B 模型同样面对，且成本增加 20x）

**决策**: ✅ **策略D 有限注意力随机采样 + 度数加权（α=0.5）**

- 每节点每轮按 $P_i \propto d_i^{0.5}$ 加权采样，最多读取 **10 个**邻居
- 每个邻居保留最近 **k=3 轮**发言（由 k=5 调整）
- 估算 token 消耗：10 × 3 × 65 ≈ 1,950 tokens，加系统提示约 **2,500-3,000 tokens**，全部节点行为一致，无需对 hub 特殊处理
- α=0：均匀随机（无影响力差异）；α=0.5：大V被采样概率更高但不垄断注意力
- **社会学隐喻**：有限注意力（bounded attention）+ 算法热度加权推送
- **Phase 0 敏感性分析**：同时测试 α=0 与 α=0.5，与 m 值敏感性分析合并进行

**论文表述**：*"为模拟现实社交媒体中的有限注意力机制，每个智能体每轮从其网络邻居中按度数平方根加权采样不超过10个节点的最近3轮发言作为信息输入。"*

### [M4] 角色漂移（Persona Drift）是强混淆变量 ✅ 已解决

**问题描述**
多轮对话后 LLM 会逐渐偏离初始角色。关键不对称：
- Instruct 模型因安全训练，在对话中**更容易主动放弃极端角色**
- Abliterated 模型安全向量切除后，维持极端角色的能力更强

**后果（原判断）**
观察到的收敛可能不是 RLHF "生成式把关"效应，而只是 Instruct 模型更难维持极端角色扮演。

**决策**: ✅ **角色漂移重新定位为中介机制，而非混淆变量**

论证链条：
```
RLHF 安全训练 → 模型被训练成"拒绝维持极端立场"
    → 多轮对话中主动软化角色（角色漂移）
    → 观点向中庸收敛
    → 这正是"生成式把关"的机制本身
```
角色漂移是 RLHF 把关效应的一条具体实现路径，是因变量的一部分，而非噪声。

**前提条件（已满足）**：abliterated 模型保留完整 SFT 训练，角色扮演能力与 Instruct 版相同，仅安全向量切除。两组第1轮均能正常建立角色，差异从第2轮起由安全机制主导，论证链条完整。

**新增补充指标：角色一致性得分（Persona Consistency Score）**
```
角色一致性得分 = cosine(embed(第t轮输出), embed(初始角色描述))
```
- 预期：网络A（Instruct）角色一致性随轮次单调下降；网络B（abliterated）保持相对稳定
- 作为论文**机制验证图**，解释"为何 Instruct 网络收敛更快"的内在路径
- 嵌入模型复用 `BAAI/bge-large-zh-v1.5`（与 F3 验证指标共用，无额外成本）

### [M5] 缺乏零模型基线（Null Model） ✅ 已解决

**问题描述**
没有与 LLM 行为无关的基线。若一个随机输出的系统也会收敛，则收敛可能只是网络动力学的自然结果，与 LLM 对齐无关。

**决策**: ✅ **无需额外实验，通过文献定位与局限性声明处理**

**论证**：已有 Nature 论文正式证明"在 LLM 主导的意见网络中，观点坍缩是长期动力学的必然结果"。"收敛是否发生"已是已知结论，本研究的核心问题是**安全对齐机制是否加速/加剧了这一过程**，零模型基线对此论证无威胁。

**论文写作处理**：
- **Introduction/Related Work**：明确引用该 Nature 论文，定位为"在已证明坍缩必然性的基础上，进一步揭示 RLHF 安全对齐对坍缩速率的调节效应"
- **局限性章节**：承认未设置随机基线，说明理由——已有文献支撑收敛必然性，本研究聚焦于对齐机制对收敛速率的差异效应

### [M6] 5 次重复统计功效不足 ✅ 已解决

**问题描述**
实验有三个独立随机源：LLM temperature 采样 + BA 网络随机生成 + 每轮随机激活节点。
n=5 时，中等效应量下 t 检验功效（1-β）≈ 0.3-0.4，远低于学术标准 0.8。

**决策**: ✅ **采用线性混合效应模型（LMM），n=5 次重复即满足统计功效要求**

```
模型结构：方差 ~ 轮次 × 组别 + (1+轮次|run_id)
有效观测：50轮 × 5次 = 250个时间点，功效远超 0.8
```

- **固定效应**：轮次主效应、组别主效应、轮次×组别交互项（核心：两组收敛斜率差异）
- **随机效应**：每次独立运行（控制运行间随机变异）
- **优势**：保留完整时序信息，输出"方差随轮次变化轨迹"，配置信带直接作为论文主图
- **补充**：t 检验辅助报告热寂半衰期描述统计（均值±SD）
- **实现**：`statsmodels.formula.api.mixedlm`，代码简单，符合计算社会科学顶刊规范

### [C1] "认知热寂"与热力学熵方向相反 ⏸️ 暂缓，待理论文章修改时联动处理

**问题描述**
热力学热寂 = 最大熵 = 最大**无序**。
但实验测量的是方差趋近于 0，即最大**有序/同质化** = 最低熵。
两者方向相反，概念基础存在内在矛盾。

**候选方向（待理论文章修改时选定）**：
- **相变到有序态**（Order-Disorder Phase Transition）：磁矩整齐排列类比，方向吻合，但强调突变临界点，与渐进收敛不完全匹配
- **耗散结构坍缩**（Dissipative Structure Collapse）：普里高津理论，RLHF 把关作为负熵过滤器，理论对应最深，但术语门槛高
- **认知结晶化**（Cognitive Crystallization）：液态→晶体类比，多元流动变僵化一致，对社科读者友好
- **坚守"认知热寂"并重新定义**：将其语境化为"意见场动力学死亡"——同质到极致与无序到极致均意味着有效信息消亡与系统活性终结，共同点是系统失去产生有效差异的能力

**暂缓理由**：概念命名与理论文章高度耦合，需两篇文章保持一致，待理论文章修改时统一框架后再决定。

### [C2] SFT 与 RLHF 混淆——无法孤立"对齐"效应 ✅ 已解决（由 F1 决策连带解决）

**问题描述**

**决策**: ✅ **F1 的 C-abliterated 方案连带解决此问题**
- Abliterated 模型 = 相同 SFT + 相同 RLHF 权重结构，仅安全对齐方向向量被置零
- 两组差异精确对应"安全对齐向量"，SFT 混淆被完全消除
- 论文可明确声称"因变量归因于 RLHF 安全对齐训练"

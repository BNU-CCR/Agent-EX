## D-2026-07-14-01：Paper 1 聚焦矩阵

**状态：** 已确认。
**决定：** 采用 identity 2 × continuity 2 × social exposure 3 的12 cells；唯一 primary outcome 为 `Δlog((B+ε)/(W+ε))`；唯一 primary estimand 为 continuity 对 `WS-shuffled` 的 matched-seed DiD 调节。正式规模 N=1000、T=50、首批10 matched seeds，按一次盲态 nuisance-variance 重估最多20个。

**理由：** 将身份信息、历史连续性和网络暴露拆开识别，避免 pilot 的复合 prompt confound；N 与 seed 分别解决网络规模和独立重复问题。

**未选择：** weak/lifelong × BA/WS 主矩阵；把 RLHF、动态重连或多模型并入 Paper 1。

## D-2026-07-16-01：开放权重主模型与 API 稳健性分工

**状态：** 已确认策略；部分运行字段待 Phase 0B 冻结。
**决定：**

- 主模型使用 Qwen3-8B BF16、non-thinking，通过 vLLM 自部署，运行完整正式矩阵。
- 固定精确模型 revision；其 hash 记为 `UNRESOLVED[P1_MODEL_REVISION]`，由 Phase 0B 实测后冻结。
- Paper 1 主实验不微调权重；不把量化权重与 BF16 主矩阵混用。
- API 仅运行预注册的固定 snapshot 外部稳健性子集；推荐的核心8 cells 只是会审候选，不是 schema 常量。最终可从12个 canonical cell IDs 中审批1至12个不重复 cells，并由 `UNRESOLVED[P1_API_ROBUSTNESS_CELLS]` 冻结；N/T/seeds 暂拟 N=200、T=50、5 matched seeds并由 `UNRESOLVED[P1_API_ROBUSTNESS_SCALE_FREEZE]` 冻结。
- API 与开放模型的差异只能解释为模型系统稳健性，不得解释为“API 部署效应”。

**理由：** 固定权重、tokenizer、模板和推理栈提高百万级生成的可追溯性和可复现性；API 提供有限外部效度而不支配主检验。

**未选择：** 全矩阵依赖滚动 API 别名；在 Paper 1 中用 LoRA/领域微调同时改变权重；把 API 结果纳入主假设检验。

## D-2026-07-29-01：Phase 0 议题候选集

**状态：** 已确认研究方向；不构成机器协议冻结。

**决定：**

- Phase 0 topic probe 采用三个候选：延迟退休政策、转基因食品接受、AI就业替代预测。
- 核能发展、生育支持和指定场景人脸识别不进入首轮 probe，但保留在版本化候选库，
  不视为被理论否定。
- 三个候选都须先完成单一构念、精确中文题干、量表端点和目标模型无网络 probe。
- 在查看正式网络演化结果之前冻结一个主议题；Paper 1 只允许一个议题运行完整
  12-cell主矩阵。
- 可再保留一个议题作为预注册的缩减稳健性议题；其规模和cells仍属未决项。

**理由：** 六议题统一审查中，延迟退休在政策框架、公平感和利益异质性之间最均衡；
转基因具有最完整的风险传播、信任、谣言和社交媒体证据链；AI就业虽综合排序第四，
但与项目主线高度一致，并能与前两者形成社会政策、科技风险和技术—劳动三种不同
议题类型。该组合也避免转基因与核能两个相似科技风险议题同时占用 probe 名额。

**未选择：** 按总分机械采用延迟退休、转基因、核能；让六个议题全部进入 probe；
让两个或更多议题都运行完整正式矩阵；在看到网络结果后按结果显著性选择议题。

**完整依据：** `docs/paper1-design-rationale.md` 的 `DR-P1-043` 及其逐篇文献表。

## D-2026-07-29-02：Phase 0题干、量表与候选冻结程序

**状态：** 已确认研究设计；不构成机器协议字段冻结。

**决定：**

- 三个候选均采用“中性事实卡 + 单一核心陈述”结构，事实卡不夹带正反结果框架。
- 延迟退休测量对中国现行渐进式法定退休年龄调整方案的总体支持，不混入个人退休
  意愿、养老金信心或最低缴费年限评价。
- 转基因候选限定为对依法标识的转基因大豆油在中国市场销售的支持，不混入个人购买
  意愿、对全部转基因技术的一般态度或食品安全知识判断。
- AI就业候选限定为对“未来10年生成式AI在中国减少的就业岗位多于其创造的新岗位”
  的预测判断，不混入个人岗位风险、AI总体利弊或政策偏好。
- 首选1–7全标签有序立场量表，4只表示态度中点；另记1–5自报confidence。confidence
  只作题干筛选、质量审计与敏感性描述，不进入意见更新和primary outcome。
- 输出固定为`stance → confidence → public_reason`；公开理由不是思维链。原始响应、
  文字类别、解析及重试均须保存。
- 三个候选均在目标Qwen revision上进行无网络topic probe：一个拟冻结版本加两个
  同方向等义改写，同时比较0–10量表挑战者，并检查字段顺序效应。
- 在比较三个候选结果前，采用统一质量门槛：至多一次格式重试后解析率不低于99%、
  实质拒答率不高于1%、至少使用7点中的4类、单一端点不超过80%、等义版本
  `|d| ≤ 0.20`且检查完整分布、理由—立场直接矛盾不高于5%。这些阈值是项目操作
  规则而非普适文献定律；若dry run要求调整，必须在候选比较前统一修改并留痕。

**理由：** 三个议题测量的实质构念不同，但可共享同一有序状态接口；明确事实卡、
中点和相邻构念边界，可减少题干漂移。调查量表研究支持避免类别过少和混合中点，
LLM响应偏差及置信度校准研究则要求使用目标模型probe，并限制对模型自报confidence
的解释。

**未选择：** 沿用pilot的1–10偶数刻度；把“不知道”编码为中点；仅生成自由文本后
由同一模型回评分；把三个候选的绝对均值当作同一实质构念比较；在看到网络演化结果
后再选择题干或议题。

**完整依据：** `docs/paper1-design-rationale.md` 的 `DR-P1-044` 至 `DR-P1-048`。

### 尚未冻结

- 最终完整12-cell主议题和缩减稳健性议题；
- topic probe后实际采用1–7还是触发0–10替代；
- 最终机器协议中的题干原文、hash、模型revision、chat template及采样参数；
- 依赖后续人口和persona模块的平衡身份壳敏感性测试。

### 重开条件

- 正式模型revision、chat template或采样策略改变；
- 任一事实卡或核心陈述发生实质改写；
- 三个候选均不能通过同一套质量门槛；
- 后续身份模块导致系统性构念漂移，或相关政策/法规发生实质变化。

## D-2026-07-29-03：目标人口与人口数据来源

**状态：** 已确认研究设计；不构成机器协议或人口制品冻结。

**决定：**

- 三个候选议题共用“中国大陆年满18岁、过去半年使用过互联网、生活于普通家庭/
  社区场景的居民”作为目标总体；不设64岁或法定退休年龄上限。
- 网民资格只表示进入在线舆论环境的最低覆盖条件，不等同于特定平台用户、主动
  发帖者或每轮被激活者。
- 人口数据采用四层分工：国家统计局2025年全国1%人口抽样调查提供最新总体边际，
  2020年第七次人口普查提供详细人口结构，CNNIC第57次报告提供网民定义及可得
  网民边际，CFPS2022加权成年网民样本提供联合微观结构。
- CGSS2021和CLDS仅用于预先声明的一般成年人及劳动子群外部验证，不与CFPS逐行
  拼接，也不覆盖共同目标总体。
- 正式人口制品必须保存来源版本、许可、下载日期、原始变量与缺失码、权重、
  crosswalk、清理版本、SHA-256和校准误差；正式冻结后不得随新数据静默热更新。
- 论文将其称为“由公开人口与调查资料校准的中国成年网民合成人口”，不宣称代表
  中国公众、特定平台用户或预测真实民意。

**理由：** 成年网民框同时匹配在线舆论场并覆盖三个候选议题所涉及的劳动者、学生、
消费者和退休者。多来源分工能把最新边际、详细交叉结构、网民覆盖和个体联合关系
分开处理，避免让任一汇总来源承担其无法支持的推断。

**未选择：** 全体成年人直接进入在线网络；仅限18–64岁劳动力；把CNNIC汇总表、
七普或未经校准的CFPS单独当作完整母版；独立拼接所有人口边际；使用来历不明的
微数据镜像。

**完整依据：** `docs/paper1-design-rationale.md` 的 `DR-P1-049` 至 `DR-P1-051`。

### 尚未冻结

- CFPS中“过去半年上网”的精确变量、有效样本筛选和适用权重；
- 最终人口字段、分档、prompt可见字段、校准边际及联合约束；
- IPF/校准算法、N=1000整数化、误差容差、缺失与稀疏单元的机器规则；
- 各输入文件的实际版本、许可记录、下载日期和hash。

### 重开条件

- Paper 1研究对象改为一般线下公众或特定平台用户；
- 正式议题依法或理论上要求限定职业/年龄总体；
- 合法可得数据无法稳定识别成年网民或来源间定义无法形成可审计crosswalk；
- 高龄、非劳动参与者或其他关键子群在probe中出现系统性构念偏离。

## D-2026-07-29-04：人口字段分层与最小共同身份卡

**状态：** 已确认研究设计；不构成字段crosswalk、人口边际或Persona模板冻结。

**决定：**

- 同一人口记录将字段分为`calibration_fields`、`identity_visible_fields`、
  `analysis_audit_fields`和`topic_extension_fields`四类用途；数据中存在某字段
  不等于允许将其写入prompt。
- 共同人口字段至少保留年龄、调查记录性别、最高教育、当前城乡、主要活动/劳动
  状态和职业；宏观区域、户口、婚姻、收入分位、互联网频率及原始职业编码主要
  用于分析和审计。
- `identity_present`采用结构化、非叙事的最小共同身份卡，依次显示年龄段、调查
  记录性别、教育、当前城乡、主要活动/劳动状态，以及就业者的宽口径职业组。
- 三个候选议题使用完全相同的可见字段、顺序、标签和粒度；不允许模型生成姓名、
  个性故事、兴趣或其他未提供的生活细节。
- 身份因素解释为“是否向Agent提供经验约束的最小社会人口位置卡”，是一个捆绑
  处理；主矩阵不识别各人口字段的独立因果效应，也不宣称恢复真实群体意见。
- 姓名、精细地点、雇主、政治/宗教身份、人格、价值、制度信任、议题知识/好恶、
  风险认知、失业担忧、个人退休意愿及其他初始立场近邻变量不得进入共同身份卡。
- 硬校准只使用与成年网民总体定义兼容的可靠边际，不将一般人口边际未经互联网
  资格调整直接套用，也不对全部字段做笛卡尔积poststratification。
- 正式freeze前必须核对原始变量、crosswalk和缺失码，并执行单字段移除、字段顺序、
  无关字段placebo、立场泄露和刻板印象审计；不合格字段降为analysis-only。

**理由：** 三个议题的经验研究都提示基础社会位置可能关联态度异质性，但这种相关
不能证明人口提示能准确模拟群体。现有LLM研究同时显示人口persona的收益有限且依赖
模型、措辞和任务，并可能压平或刻板化群体。因此采用最小共同身份卡，把较丰富的
人口信息留在分析层，能够保留实验操纵而限制过度人格化。

**未选择：** 所有人口字段均写入prompt；按议题改变身份卡；自由生成叙事Persona；
只因变量与态度显著相关就显示给模型；把姓名或地域当作人口属性的隐式代理；以
完整字段笛卡尔积建立N=1000硬配额。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-003`及`DR-P1-052`
至`DR-P1-055`。

### 尚未冻结

- CFPS2022精确source variables、成人网民有效样本、权重及字段crosswalk；
- 年龄分档、劳动状态和职业宽类的最终机器标签与中文显示原文；
- 各人口边际、联合约束、校准容差和N=1000整数化算法；
- `identity_present/absent`四套Persona模板、长度控制、template hash及probe结果。

### 重开条件

- 目标模型probe显示最小身份卡仍产生明显构念漂移、立场泄露或群体贬损；
- 正式数据不能支持任一核心字段或成年网民兼容边际；
- 三个议题对同一身份卡的理解发生系统性不等值；
- 研究问题改为识别单个人口属性效应或某个特定身份群体。

## D-2026-07-29-05：初始立场、初始理由与round-0状态

**状态：** 已确认研究设计；不构成初始化制品、理由库或审计阈值的机器冻结。

**决定：**

- 正式主实验在1—7量表上采用受控、对称、单峰的初始立场分布。N=1000时七档人数
  固定为`[50, 100, 200, 300, 200, 100, 50]`，对应均值4、总体方差2.10和10%的
  两端点比例。该分布是透明的实验初始条件，不宣称代表中国公众的真实态度分布。
- 七档均匀分布只可作为Phase 0小规模挑战者；若未来获得与最终题干、1—7量表和
  成年网民总体等值的人类调查，可将经验分布作为预注册敏感性条件。目标模型自由
  生成和预设双峰分布不进入正式主初始化。
- 初始立场与人口身份字段采用约束正交分配。同一matched seed中，每个`agent_id`的
  人口、初始立场和初始理由在12个cells完全匹配；不同seeds保持相同档位人数，但以
  独立初始化RNG重新置换Agent映射。
- 初始组按round 0固定为`low_initial=1..3`、`midpoint_initial=4`和
  `high_initial=5..7`，不得按终点重分；主分布对应350/300/350人，以300作为该
  分布下的运行前最小组硬门槛。
- 初始理由采用“来源支持的论据家族+冻结模型受控改写+机器审计+分层盲态人工审计”
  的离线理由库。理由不得包含身份、邻居、社会曝光、连续性指令、显式立场分数或
  未核实的统计/引文。
- 每个Agent在round 0必须拥有一个有效立场和一条公开理由；round 0不是一次互动。
  不再使用概率性初始发帖。同一matched seed跨cells逐Agent复用完全相同的理由；
  不同seeds从同一冻结库按独立reason-assignment seed确定性映射。
- 初始confidence仅可作为1—5审计元数据，不显示给Agent、不进入曝光、不决定更新
  强度，也不得从立场极端度机械推导。
- 理由生成prompt、模型revision、原始候选、入选集、审计结果、去重报告及hash必须
  全部可追溯；审计失败条目在正式冻结前重生成，运行时不得用空白/中性占位回退。

**理由：** 初始意见分布会影响共识、聚类和极化，预设双峰会把待解释结果写入基线；
目标模型自由初始化则会把模型默认立场混入人口条件。传播学的persuasive-arguments
研究同时表明，论据方向、新颖性与可接受性会改变极化或去极化，因此初始理由必须
作为独立实验刺激冻结，并与身份和continuity处理分离。

**未选择：** 直接移植不等值调查比例；七档均匀分布作为主分布；目标模型自由决定
初始立场；少量重复正反模板；未经审计的自由理由生成；真实社交媒体原文直接进入
理由库；概率性缺失round-0发帖；把初始confidence作为更新权重。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-056`至`DR-P1-060`。

- 三个候选议题的论据家族、来源台账、理由生成prompt和生成模型revision；
- 理由长度的最终边界、候选库规模、语义近重复阈值、judge/NLI阈值、人工编码流程
  及编码者一致性门槛；
- 最终理由文本、Agent映射、版本与全部SHA-256。

### 重开条件

- Phase 0显示建议单峰分布在目标模型上造成解析、端点吸附或机械性收敛；
- 获得与正式题干、量表和目标总体等值的高质量调查；
- 约束正交化无法在N=1000下满足人口平衡且不产生结构异常；
- 理由库在不同立场档之间无法实现长度、论据家族、事实风险和可读性的可接受平衡；
- 最终主议题、目标模型或round-0传播语义发生实质变化。

## D-2026-07-29-06：Persona四模板的正交骨架与非锁死连续性

**状态：** 已确认研究设计；不构成模板原文、ID、阈值或hash的Phase 0冻结。

**决定：**

- identity×continuity四条件由一份共同骨架确定性插入`identity_block`和
  `continuity_block`生成，不分别手写四份近义Persona，也不再使用weak/strong/
  lifelong线性强度。
- 共同骨架固定组织共同任务边界、因素块、议题事实卡/量表、自身历史、社会曝光、
  当前轮任务和统一JSON输出schema。除两个因素块外，四条件的可见文本、字段顺序、
  标点、换行和输出合同必须逐字节相同。
- `identity_present`只提供结构化最小人口字段卡：年龄段、调查记录性别、最高教育、
  当前城乡、当前主要活动，以及就业者的宽口径职业组；同时说明这些背景不预设立场，
  不得补写姓名、性格、爱好、经历故事或其他未提供身份。
- `identity_absent`真正省略身份块，不写“普通中国人”“中立公众”“没有特定身份”
  等替代Persona，也不使用具有社会含义的等长placebo。
- `continuity_present`只要求参考此前立场、理由和历史发言，使本轮判断在解释上
  连贯；对保持与改变提供对称许可。若保持，说明当前主要依据；若改变，指出促使
  重新权衡的信息，并明确不得仅为保持一致而忽略有说服力的信息。
- `continuity_absent`真正省略连续性块，但接收与C1完全相同的自身历史事实、曝光
  和共同作答合同。因此continuity检验的是显式解释连贯要求，而不是有无记忆。
- 所有条件禁止“坚持、捍卫、忠于、抗从众、不要被影响、除非证据确凿、最大变化
  一步、保持原有价值观、永不改变”等意见锁定或额外反向说服门槛。
- Phase 0按结构差异、identity uptake、刻板印象/泄露、continuity连贯性、强反向
  信息下仍可改变、解析/拒答/构念有效性六类gate冻结模板；不得依据网络结果方向
  选择模板。
- 共同骨架、因素块、渲染器和完整模板分别版本化与hash。freeze后任何可见字符、
  标签、顺序、换行或分隔符改变均产生新版本，formal run只引用固定ID和hash。

**理由：** 社会人口Persona研究显示提示可能改变模型行为，但效果高度依赖模型、
任务和措辞，并可能误描绘、压平或刻板化身份。LLM意见动力学研究又显示既往意见
可见性会提高历史一致性，而强confirmation-bias提示可能人为制造碎片化。因此采用
最小身份卡、真省略基线和非锁死连续性块，并以同一骨架机械保证因素正交。

**未选择：** 四份独立手写Persona；“普通人/中立者”基线；身份故事自由生成；
按议题改变共同身份字段；weak/strong/lifelong复合强度；用坚持或抗从众措辞实现
continuity；有无历史与continuity同时变化；为等token加入语义placebo；按预期
极化方向挑选prompt。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-061`至`DR-P1-065`。

### 尚未冻结

- 共同任务边界和两个因素块的最终逐字原文、标签、分隔符及渲染位置；
- 两组等义continuity候选和identity/continuity块顺序挑战结果；
- 操纵检查样本、人工编码量表、judge模型、连贯性生效阈值和锁死上限；
- 正式template ID、语义版本、tokenizer计数、各层hash及rendered prompt hash；
- Phase 0中字段移除、顺序、placebo、刻板印象和构念漂移的实际通过标准。

### 重开条件

- identity块无法被合理使用，或持续产生明显刻板化、身份扩写、拒答和构念漂移；
- continuity块未提高解释连贯性，或面对充分信息时几乎完全阻止意见更新；
- 合理等义改写或因素块顺序互换导致操纵方向不稳定；
- 最终目标模型、共同身份字段、历史语义或输出合同发生实质变化。

## D-2026-07-29-07：固定无向WS网络与结构优先参数冻结

**状态：** 已确认研究设计；不构成NetworkX版本、正式seed、结构阈值或图hash冻结。

**决定：**

- Paper 1主网络采用标准Watts–Strogatz无向简单图：`directed=false`、无自环、无
  重边、N=1000全部节点全连通，T=50期间边表固定，不做意见驱动或模型决定的重连。
- 边解释为固定讨论环境中的稳定相互可见接触，不代表真实平台关注、好友、推荐或
  因果关系；论文不宣称复刻微博、微信、抖音或其他实际网络。
- 以偶数`k=10`、`p=0.05`作为正式主网络首选锚点，对应5000条边。该值是稀疏性、
  局部聚类、路径、degree-matched shuffled构造和潜在资源成本的项目折中，不是
  经验平台参数或文献常数。
- 机器冻结前必须在不调用LLM的纯结构gate比较
  `k∈{6,10,20} × p∈{0.02,0.05,0.10}`，并用锁定NetworkX版本、预注册候选seeds
  和统一审计函数复算。参数只能按结构/资源gate选择，不得按极化或处理效应方向选择。
- 每个matched seed生成一张图；同seed的有序edge list、Agent—node映射和图hash在
  12 cells完全复用。WS图与Agent位置不随cell变化。
- 已冻结Agent记录用独立`node_assignment_seed`随机映射到WS节点；不得按agent_id、
  初始立场、年龄或其他人口字段排序后放入环，以免机械制造局部同质性。
- `graph_seed`、`node_assignment_seed`、population、initialization、reason、
  activation、exposure和model sampling使用独立RNG namespaces。
- 正式图必须验证节点集合、边数`N×k/2`、端点、无自环/重边/孤点、全连通、规范
  edge排序和hash。运行时任一失败即`on_invalid=fail`，不得静默修边、取giant
  component或临时重抽。
- 冻结前若标准WS候选不连通，只能按预注册确定性候选seed序列选择下一张合格图，
  保存全部失败attempt和原因；任何LLM运行开始后不得换图。
- 结构gate报告平均度/SD、最小/最大度、密度、聚类/传递性、平均最短路径、直径、
  分量、三角形及相对环格和同规模随机图的small-world指标。BA仅可作为后续少量
  拓扑稳健性扩展，不进入主矩阵。

**理由：** WS模型为局部聚集和少量远距捷径提供可控基准。N=1000候选预计算中，
`k=10,p=.05`保留较高聚类并显著缩短规则环路径；但意见动力学对网络参数的反应依赖
具体更新规则，所以必须依据结构而非结果方向冻结参数。全连通、随机节点映射和跨
cell复用能避免可达性及初始立场空间排列成为隐藏处理。

**未选择：** 有向非标准WS作为主图；giant component加小分量；动态重连；直接沿用
pilot的`k=4/6,p=.1`；把测试fixture值当正式参数；按初始立场排序节点；运行时修边、
截取分量或反复重抽；根据哪张图产生更强极化选择seed；把BA塞入主矩阵。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-066`至`DR-P1-070`。

### 尚未冻结

- NetworkX及其依赖的锁定版本、生成函数和随机数实现；
- 正式`k,p`机器值、结构gate阈值、候选优先序及资源上限；
- 正式graph/node-assignment seeds、失败候选清单、edge lists及图hash；
- small-world指标的精确实现、随机/环格null生成规则和重复次数；
- BA拓扑稳健性是否实施及其独立协议。

### 重开条件

- 正式NetworkX和seed集不能复现`k=10,p=.05`的小世界结构或稳定连通性；
- 模块8曝光/上下文预算与k=10无法兼容；
- scale gate显示N变化导致结构指标或主要对比不可接受地漂移；
- 标准WS生成过程或degree-matched shuffled构造发现新的不可修复偏差。

## D-2026-07-29-08：主过程采用异质加权随机顺序激活

**状态：** 已确认研究方向；不构成活跃权重分布、时间标签、事件序列、schema或
制品hash的机器冻结。

**决定：**

- Paper 1优先追求舆论过程仿真，不再以N=1000全部Agent每轮同时更新作为主过程。
- 保留已批准的固定WS关系骨架；每个Agent获得一个在任何LLM输出前冻结的长期活跃
  权重，每次事件按权重有放回抽取一个Agent。
- 被激活Agent读取事件前已经提交的最新可见帖子和自身状态，生成新立场/理由后立即
  提交。因而同一观测周期内后续事件可以看到较早事件产生的内容。
- 未激活Agent的意见不变，但其最近一条公开帖子持续可见；Agent可在一个观测周期内
  多次发言，也可能不发言。
- T=50解释为50个观测周期`sweeps`。每个sweep恰含N次激活事件；正式N=1000时每个
  run共50,000次事件生成。群体指标、主要终点和checkpoint在sweep边界计算，事件级
  原始记录全部保存。
- 同一matched seed的12 cells共享逐Agent活跃权重和完整事件激活序列。权重和序列
  不得由意见极端程度、文本内容、cell处理或运行结果内生改变。
- 全员同步降为最大参与强度/无活跃异质性的稳健性上界；Hawkes、自激参与、重尾等待
  时间和意见驱动发言概率不进入Paper 1主过程。
- 正式10个matched seeds仍预计600万次生成，扩至20个仍为1200万次。该变更提高过程
  真实性，不以减少请求量为目的。

**理由：** 在线讨论存在沉默多数、活跃少数和高度不均的发言贡献；激活制度与节点
活跃异质性能够改变共识速度、聚类和碎片化。全员同步可用于受控机制上界，却会机械
制造人人等频率阅读—更新—发言的高密度舆论场，不适合作为唯一真实过程近似。加权
随机顺序激活在不改变固定WS关系骨架的前提下，引入发言机会差异和事件级接力传播，
同时通过跨cell共享序列保留matched比较。

**未选择：** 全员同步作为主过程；每轮无放回全体随机排列；只按固定比例抽取且
窗口末同步提交；让意见极端者自动获得更高发言率；动态重连；直接使用Hawkes或昼夜
节律；把更少的LLM调用误写成选择异质激活的主要依据。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-071`至`DR-P1-072`，
以及`findings.md`的“模块8重开：从受控波次转向舆论过程仿真”。

### 尚未冻结

- 活跃权重分布族、参数、截断、与人口/网络度数的独立性及校准目标；
- 零发言比例、top 1%/10%贡献份额、激活Gini和个体最大事件数等Phase 0 gate；
- `activation_weight_seed`、`activation_sequence_seed`和50,000事件制品；
- sweep是否附加自然时间标签，以及event/sweep/checkpoint的最终命名；
- 事件失败、重试、恢复和跨run批处理的精确语义；
- E1/E2在事件级“最近帖子”下的来源映射、消息数、排序和持久性；
- 自身记忆由“最近K轮”改为“最近K次自身发言”后的K值；
- 对现有聚焦规格、纸面协议、schema、manifest和测试的正式修订。

### 重开条件

- 无法找到有依据且不依赖意见结果的活跃权重校准；
- 顺序依赖使N=1000、T=50在正式资源gate下不可运行或无法可靠恢复；
- 极少数高活跃Agent在所有候选校准中机械支配结果；
- 事件级更新破坏E1/E2的可识别剂量匹配且无法重新定义；
- 研究目标重新收束为受控同步波次而非舆论过程仿真。

## D-2026-07-29-09：私人意见更新与公开表达分离

**状态：** 已确认研究方向；不构成发帖倾向分布、分析端点、schema或制品hash冻结。

**决定：**

- 每个激活事件首先是一项注意/阅读和私人意见更新机会，不再自动等同于公开发帖。
- 被激活Agent用一次LLM调用生成新的私人立场和理由；私人状态无论是否公开都立即
  提交并进入完整证据链。
- `publish_flag`由任何LLM运行前冻结的外生表达过程预生成。主过程不允许模型自行
  决定是否发帖，也不让当前意见、极端程度、消息内容或cell处理改变发帖机会。
- 当`publish_flag=true`时，本次立场的文字标签和理由更新为该Agent最近公开帖子；
  为false时，公开帖子保持不变。
- E1/E2只能读取其他Agent的公开帖子，不得读取私人状态。未公开更新仍可进入Agent
  自己的私人历史，但精确可见窗口另行会审。
- 注意/更新活跃权重与公开表达倾向使用独立RNG namespaces和制品；同一matched
  seed的12 cells复用逐Agent倾向与逐事件publish flags。
- round 0统一初始公开理由暂时保留，待事件级曝光整体会审时复核其启动语义。

**理由：** 在线讨论中的沉默用户仍可能阅读信息并改变判断。把发帖作为唯一意见更新
机会会机械冻结潜水者；让每次私人更新都自动公开又会消除潜在人群意见与可见舆论之间
的表达差距。两阶段设计在不增加LLM调用数的前提下保留这一区分。

**未选择：** 只有发帖者才更新；每次更新必然发帖；让LLM自由决定是否公开；让极端
意见或某一处理条件获得更高发帖概率；为私人更新和公开帖子各调用一次LLM；当前阶段
直接引入由毒性、反馈或受欢迎度驱动的内生表达。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-078`。

### 尚未冻结

- 注意权重与表达倾向各自的分布、参数、相关性和人口/网络约束；
- `publish_flag`的时间相关性、结构性潜水者比例、贡献Gini及top-user份额；
- 私人意见分布和公开可见分布的primary/secondary排序；
- 私人理由记忆、公开帖子的持久时间、重复阅读和round-0启动规则；
- event、private state、public post和exposure记录的schema及hash。

### 重开条件

- 一次调用生成的理由不能同时作为私人判断依据和潜在公开表达；
- 私人—公开分离导致无法解释或无法验证的状态漂移；
- 需要研究意见极端程度、讨论氛围或社会反馈对发帖选择的内生作用；
- 目标从在线舆论过程转为只观察公开内容而不推断潜在意见。

## D-2026-07-29-10：私人意见为唯一primary，公开舆论为预注册secondary

**状态：** 已确认研究方向；不构成公开指标公式、secondary推断或analysis hash冻结。

**决定：**

- Paper 1唯一主要结果使用每个sweep边界全部N个Agent的当前私人立场，每个Agent
  等权一次。现有`S_t`、`ΔS_T`和primary matched-seed DiD均以私人状态计算。
- 公开舆论不增设第二个primary，也不得在私人primary未达到预期时替换主要结果。
- 必须预注册并报告三类secondary：
  - `public_stock`：sweep边界每个Agent最近一条公开帖子的等权分布；
  - `public_flow`：该sweep全部新公开帖子的消息加权分布，允许高活跃Agent重复；
  - `expression_gap`：公开存量/流量相对于同sweep私人意见分布的差异。
- `private_state`、`public_stock`和`public_flow`必须在数据、指标、图表和论文中分别
  命名；不得合并为模糊的“意见分布”。
- 无新帖时公开存量仍由持久帖子定义；公开流量按预注册缺组规则处理，不得用旧帖子
  补成新流量。

**理由：** 私人分布直接回答Agent是否发生极化、均质化或漂移；公开流量还同时受到
表达选择和活跃度影响。把公开流量设为primary会混淆“意见变化”与“谁更爱说”。
保留唯一私人primary并强制报告公开存量、流量和表达偏差，既维持可识别主检验，又
展示模拟舆论场的可见性机制。

**未选择：** 只分析公开帖子；公开流量作为唯一primary；私人和公开双primary；
根据哪套分布更显著选择论文结论；把公开流量称为实际曝光或阅读量；把模拟表达偏差
直接解释为真实沉默的螺旋。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-079`。

### 尚未冻结

- 三类公开secondary的极化、均值、方差、组内/组间和文本指标公式；
- `expression_gap`的精确距离/差值定义；
- 空流量、重复发帖、sweep边界和多重检验规则；
- analysis schema、指标版本、制品hash和可视化模板。

### 重开条件

- 研究问题明确改为只解释可见平台内容而不研究Agent私人意见；
- 私人状态无法被目标模型稳定、有效地测量；
- 两阶段状态在Phase 0中持续发生无法解释的脱钩；
- primary estimand或量表构念发生实质改变。

## D-2026-07-29-11：hurdle–Beta公开表达与独立注意过程

**状态：** 已确认分布结构；不构成潜水比例、Beta参数、注意权重或校准制品冻结。

**决定：**

- 所有Agent均具有严格大于0的注意/私人更新权重。结构性潜水者仍可阅读、接收曝光
  并改变私人意见；潜水只表示round 0后不再公开发帖。
- 公开表达使用hurdle–Beta模型：先分配结构性潜水者；潜水者后续发帖概率为0；
  非潜水者的个体表达倾向从Beta分布生成；逐事件`publish_flag`由该倾向和冻结RNG
  预生成。
- 主模型中注意权重与表达倾向独立，并分别与人口、初始立场、WS度数及实验cell
  独立。正相关注意—表达关系只作为预注册敏感性，不得扫描多个相关值后挑结果。
- 参数必须在不读取意见演化结果的校准中匹配零新帖比例、均值/方差、发帖Gini、
  top 1%/10%贡献份额、最大个人份额、每sweep总帖数及其跨sweep变异。
- 不直接套用任一平台的单个百分比/幂律指数，也不使用coder指定的三档活跃类型。

**理由：** 纯连续发帖概率难以明确区分结构性潜水者与偶然零发帖者；固定三档则人为
制造边界。hurdle–Beta可以同时表达长期沉默和贡献者内部的连续异质性。让所有Agent
仍具有正注意权重，可避免把不发帖误写成不阅读或私人意见冻结。

**未选择：** 每人相同发帖概率；只有连续Beta而无hurdle；潜水者不阅读；固定三档；
模型自主决定发帖；意见越极端自动越活跃；直接复制“90-9-1”规则；按极化结果选择
潜水比例、Beta参数或注意—表达相关强度。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-080`。

### 尚未冻结

- 结构性潜水比例、Beta参数及参数校准算法；
- 注意权重分布族角色已由`D-2026-07-29-12`确认；精确参数、截断、最大份额与跨N
  缩放仍未冻结；
- 正相关敏感性的构造方法和强度；
- 经验数据源、目标区间、损失函数、容差、seed数及失败规则；
- round-0帖子是否计入表达过程统计。

### 重开条件

- hurdle模型无法同时复现零新帖比例和贡献不平等；
- 结构性潜水者假设造成不合理的永久表达冻结；
- 获得能联合观测阅读和发帖的高质量数据，支持不同联合过程；
- Phase 0显示独立注意—表达假设导致明显不合理的公开/私人脱钩。

## D-2026-07-29-12：截断对数正态注意权重及分布族挑战

**状态：** 已确认分布族角色与校准框架；不构成精确参数、阈值或权重制品冻结。

**决定：**

- 主模型使用严格大于0的截断对数正态长期注意权重，并在每个matched seed内归一化
  为`sum(w_i)=N`。
- 同一matched seed的12 cells复用完全相同的权重向量及其预生成激活序列。
- 截断Pareto作为预注册的更重尾敏感性；全部`w_i=1`作为无异质性机制基线。
- Phase 0按权重/实现激活Gini、top 1%/10%份额、最大个体份额、有限T零激活比例、
  跨sweep波动和跨N稳定性校准；不得读取意见方向、极化或均质化结果选择参数。
- 精确分布参数、截断、目标区间、容差、候选网格、seed、失败规则和制品hash继续
  保持`UNRESOLVED[...]`，通过非结果导向的Phase 0过程gate后才能冻结。

**理由：** 既有研究支持活动率异质性，却不支持跨平台唯一的分布族；Twitter活动
数据曾更符合对数正态，其他网络则可能更符合截断幂律。以可控尾部的截断对数正态
作为主模型，并用Pareto和等权挑战，可以将“存在异质性”与“特定尾部形状”区分开，
同时避免少数Agent在N=1000下未经约束地主导整个事件序列。

**未选择：** 未截断幂律作为唯一模型；按平台公开发帖数据直接声称复原隐性阅读；
固定三档注意类型；允许零注意权重；根据极化结果选择分布族、参数或截断值。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-081`。

### 尚未冻结

- 对数正态、Pareto的全部精确参数及归一化/截断算法；
- 校准目标区间、容差、损失函数、候选网格、seed数和失败规则；
- 正相关注意—表达敏感性的构造与强度；
- 正式权重制品、RNG namespace、算法版本和hash。

### 重开条件

- 主分布无法通过预注册过程gate；
- 结论对Pareto或等权挑战发生方向性逆转；
- 获得可联合观测阅读和发帖、且与目标总体匹配的数据；
- 截断/归一化造成明显跨N不稳定。

## D-2026-07-29-13：E1采用固定度数保持的shuffled shadow graph

**状态：** 已确认来源关系语义；不构成构图算法、结构阈值或图制品冻结。

**决定：**

- E2使用冻结WS图；E1为每个matched seed预生成一张整个run固定的无向简单shadow
  graph；E0没有社会来源。
- shadow graph逐节点精确保持对应WS图的度数，禁止自环、重边及任何真实WS边，并
  要求全图连通。Agent—节点映射跨12 cells保持一致。
- 同一matched seed的全部E1 persona cells复用同一shadow graph，全部E2 cells复用
  同一WS图；两类社会条件因此逐节点匹配潜在来源数和潜在被曝光次数。
- 图必须在LLM调用前生成、验证并hash。任何构图失败、禁边、度数不等、不连通或hash
  不符均fail fast；不得运行中重抽、修边或降低约束。
- 每sweep重新映射和逐事件重新抽样不进入Paper 1主矩阵；动态feed如需研究，必须
  作为另行预注册的稳健性或后续论文因素。

**理由：** 固定shadow graph使E1/E2都保留稳定重复联系人，只主要改变拓扑组织。
动态换人会同时改变关系周转、累计独特来源、重复曝光和社会强化，导致拓扑效应与
feed动态效应混淆。

**未选择：** 每sweep重建映射；每事件随机抽取发送者；允许shadow graph包含真实
WS边；只匹配平均度而不逐节点保度；构图失败后运行时修图。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-082`。

### 尚未冻结

- 构图算法、候选seed、attempt上限、RNG namespace和图生成库版本；
- 连通性之外的聚类、路径、同配性等结构gate及容差；
- 图、验证报告与hash制品格式；
- 每次激活读取的消息数、新鲜度、排序和空帖子规则。

### 重开条件

- 严格约束下无法稳定生成合格shadow graph；
- shadow graph没有实质移除WS的关键小世界结构；
- Phase 0发现固定shadow关系产生不可接受的伪关系记忆；
- 研究问题改为动态feed或关系形成。

## D-2026-07-29-14：有限未读优先的事件级社会feed

**状态：** 已确认feed结构；不构成容量B、首激活规则或排序制品冻结。

**决定：**

- E1/E2每次激活只将接收者上次激活游标后、曝光图邻居产生的新公开帖纳入候选。
- 候选超过`B`时取事件序列最新`B`条，更旧未读帖过期；游标仍推进到当前事件，过期
  帖不在下次补发。
- 候选不足`B`时不回填已读旧帖；没有新帖时记录显式空feed。E0不含社会feed。
- 新近性只决定入选；入选后的prompt槽位使用独立冻结seed随机排列，完整记录来源、
  事件、入选/过期状态、原始顺序、显示槽位与hash。
- 全邻居最新帖快照仅作为高暴露稳健性；相关性、立场、热度或LLM排序的推荐feed
  不进入Paper 1。

**理由：** 有限注意与消息可见性是在线传播的重要约束。每次重读全部邻居旧帖会把
高活跃接收者变成对不变内容的重复处理器；最新B条且不回填能透明地表达新鲜度和信息
损失，同时不引入专有推荐算法。入选与显示顺序分离可降低LLM位置偏差。

**未选择：** 每次读取全部邻居最近帖子；无限积压未读队列；用旧帖补足固定剂量；
按立场/相似性/热度排序；由模型自行选择阅读内容。

**完整依据：** `docs/paper1-design-rationale.md` 的`DR-P1-083`。

### 尚未冻结

- `B`、候选网格和过程gate；
- round-0/首次激活游标与同时间戳打破平局；
- 同一发送者多帖、来源覆盖和槽位对齐算法；
- 高暴露稳健性的cells、seeds和精确实现。

### 重开条件

- Phase 0出现长期高空feed率或极高过期率；
- 结论对相邻B值发生方向逆转；
- 目标模型仍表现出无法接受的位置偏差；
- 研究问题转为推荐算法或重复曝光。

## D-2026-07-29-18：严格串行事件、失败不变异与原位恢复

**状态：** 已确认事件语义；timeout、重试次数、checkpoint频率和并发预算待runtime gate。

**决定：**

- 单run严格按冻结序列串行提交，不同run/cell可并行。
- 激活序列和publish flag预生成；feed只从已提交事件构造。
- 每次有放回抽取分配run内连续全局`event_ordinal`，`event_id`由
  `run_id + event_ordinal`派生；sweep和agent_id仅为属性，不能充当唯一键。
- 失败不修改任何状态或游标；重试是同一event下的新attempt。
- 重试耗尽后run停在该event并失败，禁止跳过、插补或fallback进入主分析。
- 恢复从同一event_id继续并验证checkpoint、前序状态hash和事件链。
- sweep是观测/checkpoint边界，不是同步屏障。

**完整依据：** `DR-P1-087`。

## 一、研究问题 (Research Questions)

### RQ1: 基础事实承接（低论证强度）

LLM 多智能体网络能否复现观点均质化？

> *注：此问题为文献已有结论的承接性验证（Shumailov 2024 *Nature*；Bisbee 2024 *Political Analysis*），不构成核心 contribution。*

### RQ2: 核心贡献（高论证强度）

RLHF 安全对齐对均质化进程的加速效应是什么？角色漂移（Persona Drift）是否构成收敛加速的中介机制？

**论文核心 claim**：
> 在以 LLM 作为硅基样本的范式下，RLHF 安全对齐对观点动力学的影响呈现 **"簇内均质化 + 簇间分极"的双层结构**，其内在机制为条件分布锐化所导致的持续角色漂移。

## 二、理论框架：方向之争的统一

### 2.1 方向之争族谱

文献中"均质化 vs 极化"的方向之争并非矛盾，而是测量了**不同的概率分布**：

| 路径族 | 代表文献 | 操作方式 | 报告方向 |
|--------|---------|---------|---------|
| 族① 单 LLM 递归训练 | Shumailov 2024 *Nature* | 上一代输出 → 下一代训练 | 均质化 |
| 族② LLM 调查仿真 | Bisbee 2024 *Political Analysis* | 单 agent × N 人口画像 × 一次问卷 | 均质化（SD -51%） |
| 族③ 数值平均算子 | FJ/BCM/HK 模型 | 收缩映射 | 均质化（数学必然） |
| 族④ LLM 多 agent 互动 | Piao 2025 / Wang 2025 / Cisneros-Velarde 2025 | 多 agent × 多轮 × persona | 极化或部分均质化 |
| **本研究** | — | 多 agent × 网络 × Instruct vs abliterated × 三档议题 × T grid | **簇内均质 + 簇间分极同时发生** |

### 2.2 边际 vs 条件双视角

- **边际分布 P(y|x)**：RLHF 锐化后单峰均质化 → WEIRD / Democratic-lean 均值（对应族①②③）
- **条件分布 P(y|x, persona)**：persona-mode 锁死，簇内方差极小，簇间被推远（对应族④）

本研究同时测量两个分布，解释"方向之争"的根源。

## 三、五子假说 (H1-H5)

| 假说 | 机制 | 操作化 | 文献证据 |
|------|------|--------|---------|
| **H1 锐化** | RLHF 单调降低条件分布 token-level 熵 | Instruct vs abliterated 输出 logits 熵差；Round 0 SD 比较 | L14 Bisbee SD -51%、效应量 +60% |
| **H2 锁死** | 条件锐化 → 跨时间步立场方差↓、persona 一致性↑ | 跨轮立场方差 + LLM-as-judge 角色一致性 + BGE cosine | L1 Piao 角色锁死、L2 Wang persona 一致性、L6 past-opinion-consistency 偏差 |
| **H3 中间空洞** | 条件锐化 × 网络聚类同质性 → 中间区域塌缩 | 评分分布 mode 计数 + 中间区间（4-6 分）密度时序 | L1 Piao 中间立场 40%→0.4-22.5%、同质互动 ~20%→48.5-88.3% |
| **H4 温度补偿** | T↑ 提升条件分布有效熵，部分抵消 H1 | T ∈ {0.3, 0.7, 1.0, 1.3} × (Instruct, abliterated) grid | L14 SI §2 temperature × variance 正相关 |
| **H5 议题敏感性** | RLHF 对敏感议题压制更强；议题语法位置触发不同强度 | 三档议题 × 议题语法位置控制 prompt | L6 safety bias 只对 Item A negative 触发，对 reasons negative 不触发 |

## 四、核心实验设计

### 4.1 网络构建

| 参数 | 设定 |
|------|------|
| 节点数 (N) | **200 agents**（正式实验）；20 agents（Phase 0 试点） |
| 拓扑结构 | 无标度网络 (Barabási-Albert)，参数 m 由 Phase 0 敏感性分析确定（候选 m=2 或 m=3） |
| 交互模式 | 每轮激活 **10-20** 个节点（5-10%，按度数加权） |
| 交互轮数 | 50 轮 × 5 重复 |
| Temperature | **主实验 T=0.7**；H4 操控变量 T ∈ {0.3, 0.7, 1.0, 1.3} |
| 记忆窗口 | k=3（每邻居保留最近3轮发言） |
| 邻居采样 | 每轮按度数平方根加权（α=0.5）采样最多10个邻居；α值由 Phase 0 敏感性分析确定（候选 α=0 / α=0.5） |
| 更新机制 | **同步更新**（所有激活节点读取上一轮快照后统一更新） |

### 4.2 Agent 设计

#### LLM Agent
- **角色设定**: 系统提示词定义人口学画像（年龄×性别×学历×职业×地区），基于 CNNIC 分布采样
- **初始观点**: 1-10 分连续 Likert，基于 CGSS/CFPS 真实分布拟合
- **记忆机制**: 本地 List 存储历史对话，滑窗保留最近 k 轮
- **Persona-free 对照**: 2×2 设计中至少一组完全不给 persona（L6 铁律 #3）

**已移除的设计**：
- ❌ ~~固执度属性~~（与角色一致性中介机制冲突，2026-05-23 移除）
- ❌ ~~SFT 微调~~（会破坏 Instruct vs abliterated 对照逻辑）

### 4.3 交互循环流程

```
每轮循环（同步更新机制）:
1. 感知与截断
   - 所有激活节点统一读取上一轮结束时邻居的状态快照
   - 从直接邻居中按度数平方根加权（α=0.5）随机采样，最多取10个
   - 每个采样邻居保留最近 k=3 轮发言，构建 Prompt
   - 估算 token：10 × 3 × 65 ≈ 1,950 tokens，加系统提示共约 2,500-3,000 tokens
   - 注：本轮任何节点的新观点在本轮内对其他节点不可见

2. 思考与更新（并发执行）
   - 所有激活节点并发调用 API 生成新观点文本 + 自报评分
   - Prompt 末尾强制输出 `【评分：X】`（X 为 1-10 的整数）

3. 广播（统一写入）
   - 本轮所有新观点统一写入，广播给直接邻居（图结构中的连接节点，非全部200个）
   - 进入下一轮
```

### 4.4 L6 Prompt 工程铁律（六条）

| # | 铁律 | 实操 |
|---|---|---|
| 1 | **显式锚定**：RLHF 触发与否取决于议题在 prompt 中的位置 | 区分议题在主语 / 谓语 / 修饰语位置 |
| 2 | **三档议题**：低/中/高 RLHF 敏感度 | 低敏（中医西医）/ 中敏（双减）/ 高敏（延迟退休） |
| 3 | **Persona-free 对照**：至少一组完全不给 persona | 2×2 设计（有/无 persona × 两组模型） |
| 4 | **离散 vs 连续**：不要被 ClosedForm "假共识" 误导 | 必须用连续 Likert 1-10 |
| 5 | **显式询问立场**：prompt 末尾强制 `【评分：X】` | 正则解析，失败即排除 |
| 6 | **议题词汇 connotation 对齐** | 同议题准备两套等价表述（中性 / 略带褒贬）作稳健性检验 |

## 五、实验分组（核心自变量）

### 主设计：2×2 结构

| | **有 Persona** | **无 Persona** |
|---|---|---|
| **Instruct（网络A）** | 主实验组 | 对照组（L6 铁律 #3） |
| **Abliterated（网络B）** | 主对照组 | 对照组（L6 铁律 #3） |

### 网络A：控制组（强对齐）
- **构成**: 100% Qwen2.5-7B-Instruct（线 A）或 Llama-3.1-8B-Instruct（线 B）
- **机制**: 测试 RLHF 对齐模型是否导致观点中庸化收敛
- **系统提示词**: 标准对齐提示词

### 网络B：对照组（安全对齐向量切除）
- **构成**: 100% 对应模型的 abliterated 版本
- **机制**: 与网络 A 架构完全相同（SFT+RLHF 权重结构保留），仅安全对齐方向向量被置零；两组唯一差异即"安全对齐"的有无
- **系统提示词**: 与网络 A 相同（两组提示词完全一致）
- **模型来源**: HuggingFace 社区版；若无合适版本，使用 FailSpy/abliterator 自行生成

### 网络C：实验组（Paper 2，暂不实施）
- **构成**: 90% Instruct 模型 + 10% Human Proxy 节点
- **机制**: 测试真实人类噪音能否抵抗 AI 同质化

## 六、实验 Pipeline（7 步）

```
Step 1: 三档议题 probe
   └─ L6 铁律 #1（议题语法位置控制）+ #2（三档敏感度）
   └─ 对每个候选议题发 50 条立场问题，统计拒答率 + BGE 余弦距离

Step 2: 人口学画像采样
   └─ 基于 CNNIC 报告，六维（年龄×性别×学历×职业×收入×地区）
   └─ 若数据不足则退到三维（年龄×性别×学历）

Step 3: 初始观点分布拟合
   └─ 基于 CGSS/CFPS 真实数据
   └─ 二元/三元分布映射到 1-10 分（Beta 拟合 vs 均匀填充，待决策）

Step 4: 零交互基线诊断（Phase 0 前置）
   └─ 200 个 agent，0 轮交互，仅 Round 0 初始输出
   └─ 测量：边际侧坍缩量化（H1 直接检验）
   └─ 目的：分离"LLM 内禀坍缩"与"网络动力学贡献"

Step 5: Phase 0 敏感性矩阵
   └─ 五维扫描：m × α × T × Persona × Model
   └─ 规模：4(T) × 2(Model) × 2(Persona) × 3(议题) = 48 次（可削减）

Step 6: 正式实验
   └─ 200 × 50 轮 × 5 重复 × 2 模型 × 3 议题

Step 7: 分析与写作
   └─ LMM + H1-H5 联合检验 + 角色一致性中介分析
```

### 7.1 双线研究策略

考虑到中文敏感议题的研究风险，**双线并行 + 双语发表**：

| 线 | 议题语言 | 模型 | 发表语言 |
|----|---------|------|---------|
| 线 A | 中文 | Qwen2.5-7B-Instruct vs abliterated | 中文 |
| 线 B | 外文 | Llama-3.1-8B-Instruct vs abliterated | 英文 |

### 7.2 部署方式：AutoDL 云端（已确定）

| 对比维度 | API调用 | 本地 CPU | **AutoDL 云端（选定）** |
|---------|---------|---------|----------------------|
| 变量控制 | 差（无法获取 abliterated 模型） | 差（无独立 GPU） | **优（fp16全精度，权重固定）** |
| 模型精度 | 不可控 | 需 INT4 量化 | **fp16 全精度** |
| 成本 | $50-500 | 免费但极慢 | **~¥40（全部实验）** |
| 可复现性 | 厂商可能更新模型 | 可复现 | **完全可复现** |
| 推荐显卡 | — | — | **RTX 4090 / 4090D（24GB）** |

### 7.3 模型选择

**线 A**：Qwen2.5 系列

| 组别 | 模型 | 来源 |
|------|------|------|
| 对齐版（网络A） | Qwen2.5-7B-Instruct | ModelScope: `Qwen/Qwen2.5-7B-Instruct` |
| 安全向量切除版（网络B） | Qwen2.5-7B-Instruct-abliterated | HuggingFace 社区版（优先）；或用 FailSpy/abliterator 自行生成 |

**线 B**：Llama-3.1 系列（待确认 abliterated 版本 availability）

**选择理由**:
1. 两组架构完全相同（SFT + RLHF 权重结构），唯一差异为安全对齐方向向量的有无
2. 两组均使用相同 chat 格式，消除交互格式混淆变量
3. 自变量精确对应"RLHF 安全对齐"，可在结论中明确归因
4. Abliteration 技术已有 Song et al. (2025) 的理论支撑（见附录）

**运行策略**:
两组实验**分时运行**（先跑完网络A全部重复 → 再跑网络B），每次只加载一个模型，使用全部 24GB，保持 fp16 全精度，无需量化。

| 框架 | 难度 | 性能 | 适用场景 |
|-----|------|------|---------|
| Ollama | ⭐ 简单 | 一般 | 快速验证 |
| **vLLM** | ⭐⭐ 中等 | **高** | **正式实验** |

## 八、测量指标（因变量）

### 8.1 主指标：观点评分时序（数值化）

每轮记录全体 agent 的自报评分（1-10），计算：
- **方差时序**：每轮观点分布方差（↓ = 多样性消失）
- **均值时序**：每轮均值漂移方向与幅度
- **收敛半衰期**：方差下降至初始值50%所需轮数

**提取方式**：Prompt 末尾强制要求输出 `【评分：X】`，正则解析，解析失败则记录异常并排除。

### 8.2 验证指标：语义嵌入相似度

- **模型**：`BAAI/bge-large-zh-v1.5`
- **指标**：每轮所有 agent 文本输出的平均两两余弦相似度（↑ = 语义趋同）
- **用途**：与评分方差趋势交叉印证；若两套指标方向一致，结论更可信

**可信度检验**：Spearman 相关系数（自报评分 vs 嵌入向量位置），ρ > 0.6 视为有效。

### 8.3 宏观网络拓扑

- **模块度 (Modularity)**：网络模块度→0 表示失去多重观点派别
- **社群数量**：动态检测观点社群演变（基于评分分段聚类）

### 8.4 机制验证指标：角色一致性得分（Persona Consistency Score）

角色漂移是 RLHF 把关效应的中介机制，需正面测量与报告：

```
角色一致性得分(t) = cosine( embed(第t轮输出), embed(初始角色描述) )
```

- **预期**：网络A（Instruct）角色一致性随轮次单调下降；网络B（abliterated）保持相对稳定
- **作用**：作为论文机制验证图，解释"Instruct 网络收敛更快"的内在路径
- **嵌入模型**：复用 `BAAI/bge-large-zh-v1.5`，与验证指标共用

### 8.5 文本多样性（补充）
- **Self-BLEU**：全体节点生成文本的词汇多样性分数

### 8.6 H1 直接检验指标：Token-level 熵

- **指标**：输出 logits 的熵值（Instruct vs abliterated 比较）
- **预期**：Instruct 的 token-level 熵单调低于 abliterated
- **操作**：零交互基线中直接测量 Round 0 输出熵差

## 九、并发执行方案

### 9.1 核心机制

模型无状态，Agent历史由实验层管理：

```
模型服务层               实验管理层
Qwen2.5-7B-Instruct  ←──  Agent 1:   历史记录 [list]
（或 abliterated）    ←──  Agent 2:   历史记录 [list]
无状态，每次请求独立   ←──  Agent 3:   历史记录 [list]
                      ←──  ...
                      ←──  Agent 200: 历史记录 [list]
```

### 9.2 推荐实现：异步并发

```python
# 控制并发数防止OOM
semaphore = asyncio.Semaphore(10)  # RTX 4090建议10

async def bounded_task(agent_id, task):
    async with semaphore:
        result = await task
        return agent_id, result
```

## 十一、关键问题与解决方案

### 问题1: 自变量孤立——如何精确测量"安全对齐"效应
**挑战**: 若对比 Instruct vs Base 模型，差异包含 SFT+RLHF 全部影响，且两者交互格式不同，产生混淆变量。
**解决**: 采用 **abliterated 模型**（安全向量切除版）作为对照——保留相同 SFT+RLHF 权重结构，仅切除安全对齐方向向量。两组使用完全相同的 chat 格式与 Prompt，唯一差异精确对应"安全对齐向量"的有无。

### 问题2: 预实验结论能否外推？
**挑战**: 5-22 预实验使用 qwen3-8b + 固执度 + temperature=0.6，与正式实验设计不一致。
**解决**: **结论不外推**。预实验仅验证代码流程，正式实验前必须完成：零交互基线诊断、议题 probe、人口学画像校准、Phase 0 敏感性矩阵。

### 问题3: 并发控制与显存管理
**风险**: 200个节点的并发请求可能OOM
**解决**:
- 两组实验分时运行，每次只加载一个模型，独占全部 24GB VRAM，fp16 全精度，无需量化
- 使用 Semaphore 限制并发数（RTX 4090 建议从 10 开始，逐步测试至 15-20）
- vLLM 启动参数：`--max-num-seqs 20 --gpu-memory-utilization 0.90`

### Agent Prompt 模板（结构化输出）

```python
SYSTEM_PROMPT = """你是一个{role_description}。
你对"{topic}"这一议题有自己的立场和看法。"""

USER_PROMPT = """你的邻居们最近表达了以下观点：
{neighbor_statements}

请表达你对上述议题的当前看法（50字以内），
并在最后一行单独输出你的立场评分，格式严格为：
【评分：X】
（X为1到10的整数，1=极端反对该议题，10=极端支持该议题）"""

# 评分提取
import re
def extract_score(text: str) -> int | None:
    match = re.search(r'【评分：(\d+)】', text)
    if match:
        score = int(match.group(1))
        return score if 1 <= score <= 10 else None
    return None
```

## 十七、研究局限性（待论文写作时展开）

### L1：同步更新 vs 异步更新
本研究采用**同步更新机制**（所有激活节点读取上一轮快照后统一更新），与 DeGroot、HK 等经典意见动力学模型对标，保证可复现性与变量控制。
然而，现实社交媒体（微博、朋友圈等）更接近**异步更新**：用户发帖后立即可见，后来者的观点已受先发帖者影响。异步机制下 hub 节点的同轮内放大效应更强，均质化可能加速。未来研究可探索异步更新机制对均质化动力学的影响，以检验本研究结论的稳健性。

### L2：预实验结论的外推限制
5-22 预实验使用 qwen3-8b（DashScope API）+ 固执度属性 + temperature=0.6，与正式实验设计（Qwen2.5-7B-Instruct / abliterated via vLLM，无固执度，T=0.7）存在系统性差异。预实验结论仅用于验证代码流程，**不可外推**至正式实验。正式实验结论需以零交互基线诊断和 Phase 0 敏感性矩阵为依据。

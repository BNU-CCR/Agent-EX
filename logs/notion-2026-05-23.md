## 2. 当前研究方案最新状态（高度浓缩）

### 2.1 研究问题

- **RQ1（基础事实承接）**：LLM 多智能体网络能否复现观点均质化。**低论证强度**。
- **RQ2（核心 contribution）**：RLHF 安全对齐对均质化进程的加速效应；角色漂移作为中介机制。**高论证强度**，拆为 H1–H5 五个子假说。

### 2.2 论文核心 claim（最新版）

> 在以 LLM 作为硅基样本的范式下，RLHF 安全对齐对观点动力学的影响呈现 **"簇内均质化 + 簇间分极"的双层结构**，其内在机制为条件分布锐化所导致的持续角色漂移。

### 2.3 实验设计骨架

- **模型**：Qwen2.5-7B-Instruct vs Qwen2.5-7B-Instruct-abliterated（线 A）；Llama-3.1-8B-Instruct vs abliterated 等同体（线 B）
- **网络**：BA 无标度，N=200，m ∈ {2,3}，α ∈ {0, 0.5}，记忆窗口 k=3，激活比例 5–10% 按度数加权
- **轮数**：50 轮 × 5 重复 × 2 模型 × 3 议题（三档敏感度）
- **更新机制**：同步更新
- **Temperature**：主实验 T=0.7；H4 操控变量 T ∈ {0.3, 0.7, 1.0, 1.3}
- **Persona**：主实验有 persona；**新增 persona-free 对照组**（L6 铁律 #3）
- **评分**：连续 Likert 1-10，强制 `【评分：X】` 格式输出
- **DV**：方差时序、均值时序、收敛半衰期、BGE 嵌入相似度、模块度、Self-BLEU、角色一致性得分
- **统计**：LMM 主分析 + H1–H5 联合检验 + 角色一致性中介分析

### 2.4 实验 pipeline
Step 1: 三档议题 probe（L6 铁律: 议题语法位置控制）

Step 2: 人口学画像采样（CNNIC 分布）

Step 3: 初始观点分布拟合（CGSS/CFPS）

Step 4: 零交互基线诊断（边际侧坍缩量化 + H1 直接检验）

Step 5: Phase 0 敏感性矩阵（m × α × T × Persona × Model 五维）

Step 6: 正式实验（200 × 50 × 5 × 2模型 × 3议题）

Step 7: LMM + H1-H5 联合检验 + 中介分析

## 3. 统一假说 H1–H5（必须记住）

### 3.1 方向之争族谱

| 路径族 | 代表 | 操作 | 报告方向 |
|---|---|---|---|
| 族① 单 LLM 递归训练 | Shumailov 2024 | 上一代输出 → 下一代训练 | 均质化 |
| 族② LLM 调查仿真 | Bisbee 2024 | 单 agent × N 人口画像 × 一次问卷 | 均质化（SD -51%） |
| 族③ 数值平均算子 | FJ/BCM/HK | 收缩映射 | 均质化（数学必然） |
| 族④ LLM 多 agent 互动 | Piao 2025 / Wang 2025 / Cisneros-Velarde 2025 | 多 agent × 多轮 × persona | 极化或部分均质化 |
| 本研究 | — | 多 agent × 网络 × Instruct vs abliterated × 三档议题 × T grid | **簇内均质 + 簇间分极同时发生** |

### 3.2 边际 vs 条件双视角

- **边际 P(y|x)**：RLHF 锐化后单峰均质化 → WEIRD / Democratic-lean 均值
- **条件 P(y|x, persona)**：persona-mode 锁死，簇内方差极小，簇间被推远

### 3.3 五子假说

| 假说 | 机制 | 操作化 |
|---|---|---|
| **H1 锐化** | RLHF 单调降低条件分布 token-level 熵 | Instruct vs abliterated 输出 logits 熵差；Round 0 SD 比较 |
| **H2 锁死** | 条件锐化 → 跨时间步立场方差↓、persona 一致性↑ | 跨轮立场方差 + LLM-as-judge 角色一致性 + BGE cosine |
| **H3 中间空洞** | 条件锐化 × 网络聚类同质性 → 中间区域塌缩 | 评分分布 mode 计数 + 中间区间（4-6 分）密度时序 |
| **H4 温度补偿** | T↑ 提升条件分布有效熵，部分抵消 H1 | T ∈ {0.3, 0.7, 1.0, 1.3} × (Instruct, abliterated) grid |
| **H5 议题敏感性** | RLHF 对敏感议题压制更强；议题语法位置触发不同强度 | 三档议题 × 议题语法位置控制 prompt |

### 3.4 文献证据对接

- H1 ← L14 Bisbee SD -51%、效应量 +60%、Power 99% 需 299 人但 ChatGPT 估计 35 人
- H2 ← L1 Piao 角色锁死、L2 Wang persona 一致性、L6 past-opinion-consistency 偏差
- H3 ← L1 Piao 中间立场 40%→0.4-22.5%、同质互动 ~20%→48.5-88.3%、L6 FreeForm Polarization-P × Negative Item A 接近双峰
- H4 ← L14 SI §2 temperature × variance 正相关
- H5 ← L6 safety bias 只对 Item A negative 触发，对 reasons negative 不触发

## 4. L6 prompt 工程铁律（六条，今天新成果）

| # | 铁律 | 实操 |
|---|---|---|
| 1 | **显式锚定**：RLHF 触发与否取决于议题在 prompt 中的位置 | 区分议题在主语 / 谓语 / 修饰语 |
| 2 | **三档议题**：低/中/高 RLHF 敏感度 | 中医西医（低）/ 双减（中）/ 延迟退休（中-高） |
| 3 | **persona-free 对照**：至少一组完全不给 persona | 2×2 设计 |
| 4 | **离散 vs 连续**：不要被 L6 ClosedForm "假共识" 误导 | 必须用连续 Likert |
| 5 | **显式询问立场**：prompt 末尾强制 `【评分：X】` | 正则解析失败即排除 |
| 6 | **议题词汇 connotation 对齐** | 同议题准备两套等价表述（中性 / 略带褒贬）作稳健性检验 |

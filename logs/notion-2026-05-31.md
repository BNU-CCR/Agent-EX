## 3. 当前 Paper 1 的定位

### 3.1 题目最新版

当前正式页标题：

> **大模型 Agent 介入下的在线意见演化机制研究——基于探索性 LLM-ABM 实验的机制识别**

这个标题是根据审稿式反馈收窄后的版本。关键词是：

- 大模型 Agent
- 在线意见演化
- 机制研究
- 探索性 LLM-ABM
- 机制识别

### 3.2 核心问题

当前不再问：

> RLHF / safety alignment 是否加速均质化？

而是问：

> **当 LLM-agent 作为新型社交机器人进入在线讨论网络后，意见演化是如何在模型默认生成倾向、persona 条件、网络互动和历史表达之间共同形成的？**

更具体：

1. weak persona 下是否更容易出现整体主流化 / 高分端集中？
2. lifelong strong persona 是否能保留更多中间立场与差异化理由？
3. BA / WS 网络结构在小规模实验中是否显著改变终点结果？
4. 立场分布上的端点集中 / 多峰化，是否等同于公共讨论意义上的多样性？

### 3.3 当前理论贡献压实为四层

正式写作页第六部分 6.1 已经重构为自然展开的贡献链条，不机械写“第一、第二、第三”，但 Claude 心里要明确它其实有四个点：

#### 贡献 A：整合贡献

把两类看似冲突的文献放进统一框架：

- LLM 生成社会科学数据 / silicon sample 研究：强调分布压缩、方差下降、长尾丢失。
- LLM-agent 网络研究：强调回音室、同质聚类、极化。

本文的整合思路：

> 独立生成阶段已经可能存在主流化和差异压缩；网络互动不会自动恢复多样性，反而可能通过邻居输入、重复回应和历史记忆，把若干高概率表达循环、放大并稳定下来。

因此，均质化与极化不是互斥结果，而是同一条件化生成机制在不同互动结构和时间尺度上的不同表现。

#### 贡献 B：机制贡献

提出：

> **LLM-agent 舆论演化不是简单社会影响，而是“条件化生成 + 网络互动 + 历史记忆”的共同过程。**

传统意见动力学里，社会影响通常被理解为节点向邻居意见靠近、远离或重新加权。

但 LLM-agent 中，社会影响不是直接作用于一个既定意见主体，而是进入下一轮生成条件：

- 议题描述；
- persona 设定；
- 上一轮立场；
- 邻居输入；
- 历史表达；
- 记忆状态。

这些共同决定下一轮会生成什么样的立场与理由。

#### 贡献 C：概念贡献

区分：

- 立场分布上的多峰 / 离散 / 端点集中；
- 公共讨论意义上的理由多样性、经验多样性、表达资源多样性。

核心判断：

> **多极化不等于多样性。**

一个系统即便呈现多个阵营，也可能只是不同局部群体各自收缩到若干高概率叙事中。如果每个局部内部理由越来越相似，边缘经验、少数立场和非典型表达不断消失，那么这种多极化并不意味着讨论空间更开放。

#### 贡献 D：社交机器人贡献

LLM-agent 不只是传统社交机器人的升级版。

传统 social bots 多被理解为：

- 信息扩散者；
- 议题放大者；
- 转发 / 点赞 / 刷屏 / 可见性操纵者。

LLM-agent 则能够：

- 生成理由；
- 回应他者；
- 模拟身份；
- 在多轮互动中维持或调整表达；
- 参与生产意见本身。

因此，它是新型社交机器人：影响的不只是信息流量和传播结构，也包括意见理由的组织方式、讨论中可见的经验类型、群体表达收敛或分化的路径。

## 4. 当前实验方案：pilot-3.0 / AI 劳动力议题

### 4.1 实验议题

议题固定为：

> **AI 是否会取代人类劳动力**

选择原因：

- 与用户课程论文 / 当前 Paper 1 最容易收口；
- 可承接预实验 1.0 的 AI 劳动力议题；
- 具备现实传播意义：AI 劳动力替代是公共讨论中的高频议题；
- 不涉及过高敏感度，适合课程论文和探索性机制识别。

### 4.2 模型

当前正式主实验使用：

- `qwen3.5-plus`
- API：DashScope / 阿里云百炼
- temperature = 0.7
- top_p = 0.9
- max_tokens = 180
- concurrency = 3
- max_retries = 2
- timeout_seconds = 60

注意：这不是 05-23 大设计中的 Qwen3-8B 本地部署，也不是 abliterated 切片。当前是课程论文 / 探索性实验的可运行版本。

### 4.3 实验规模

正式主实验：

- N = 20 agents
- T = 30 rounds
- 每组条件 5 个随机种子：42, 43, 44, 45, 46
- 每个 run 包含 20 agents × 30 轮同步更新
- 统计分析单位：condition × seed 的 run-level 指标

### 4.4 网络结构

两类网络：

1. BA 无标度网络
   - m = 2
   - 平均度约 4
   - 用于模拟中心节点 / 高连接度用户。

2. WS 小世界网络
   - k = 4
   - p = 0.1（实验代码中如此设置；论文方法页有一处可能仍写 p=0.001，建议后续核对并统一）
   - 用于模拟局部聚集与短路径传播。

注意：当前 N=20 很小，BA / WS 多轮互动后有效信息暴露容易高度重叠，所以网络差异终点效应不显著并不意外。

### 4.5 Persona 条件

最终正式主实验只保留两类：

1. weak persona
   - agent 只获得任务说明、当前立场分数、上一轮理由、邻居输入；
   - 不提供稳定身份叙事。
   - 预期：更容易向模型默认高概率叙事和邻居主流意见收缩。

2. lifelong strong persona
   - agent 获得长期职业经验、生计位置、稳定判断来源；
   - prompt 明确要求不要为了迎合邻居而突然转向；
   - 这是从预实验 2.0 lifelong prompt 思路改写到 AI 劳动力议题后的版本。
   - 预期：能保留更多中间立场和差异化理由，但不一定完全阻止整体上移。

注意：

- 早期 identity strong prompt 已作为 prompt 诊断，不进入正式主实验。
- 不能再把 lifelong 写成“稳健性实验”；它就是正式 strong persona 操作。
- 正文里如果还有 “strong persona” 泛称可以接受，但严谨写法应逐步统一为 “lifelong strong persona”。

### 4.6 四个正式条件

| 条件 | Persona | Network |
|---|---|---|
| C1_weak_BA | weak persona | BA |
| C2_lifelong_BA | lifelong strong persona | BA |
| C3_weak_WS | weak persona | WS |
| C4_lifelong_WS | lifelong strong persona | WS |

## 5. 最新实验结果

### 5.1 零交互 baseline

在没有邻居输入时：

- weak baseline:
  - mean_initial = 4.95
  - mean_parsed = 5.30
  - var_parsed = 4.85
  - parse_ok_rate = 1.0

- strong baseline:
  - mean_initial = 4.95
  - mean_parsed = 6.55
  - var_parsed = 5.63
  - parse_ok_rate = 1.0

解释：

- qwen3.5-plus 在 AI 劳动力议题上存在一定中高分倾向；
- 身份化提示会进一步提高模型对 AI 替代风险的判断强度；
- 后续意见上移不能简单归因于网络互动，而应理解为模型议题先验、persona 操作和邻居输入共同作用。

### 5.3 ANOVA 结果

以 run-level outcome 为单位，模型：

`outcome ~ C(persona_formal) * C(network)`

结果：

| 因变量 | Persona p | Network p | Interaction p | 解读 |
|---|---:|---:|---:|---|
| final_mean | .000554 | .891493 | .152237 | persona 显著，network 不显著 |
| final_variance | .339137 | .547841 | .162684 | 均不显著 |
| final_middle_ratio | .000252 | .820938 | .499917 | persona 显著 |
| final_extreme_ratio | .000012 | .900622 | .534811 | persona 显著 |
| variance_reduction | .339137 | .547841 | .162684 | 均不显著 |
| mean_abs_change_auc | .125323 | .960313 | .053592 | interaction 接近显著，但不能过度解读 |
| convergence_round | .000001 | 1.000000 | .583727 | persona 显著 |

写作结论：

- Persona 主效应非常清楚：影响最终均值、中间比例、极端比例、收敛轮次。
- Network 对当前终点结果没有显著影响。
- 不要说 persona 显著影响最终方差或方差下降幅度；它们不显著。
- H2 应写成“部分支持”或“条件性支持”，因为它通过中间立场和极端比例体现，而不是通过最终方差显著体现。
- H3 未获直接支持。
- mean_abs_change_auc 的交互接近显著，只能写作“提示趋势，需更多 seed 或扩展实验验证”。

### 5.4 结果核心叙述

当前最稳的结果叙述：

1. weak persona 条件下，agent 更容易向高分端收敛。
   - C1_weak_BA 五个 seed 全部最终均值 10、方差 0、中间比例 0、极端比例 1。
   - C3_weak_WS 也高度高分化，极端比例 0.96。

2. lifelong strong persona 不阻止整体上移，但显著抑制完全饱和。
   - C2_lifelong_BA 最终均值 7.28，中间比例 0.35。
   - C4_lifelong_WS 最终均值 7.92，中间比例 0.29。
   - 说明长期经验和稳定判断来源能保留更多非极端位置。

3. 网络结构在小 N 下不是主要解释因素。
   - BA / WS 终点差异不显著。
   - 这与 N=20 小规模有关，多轮后所有 agent 有效信息暴露高度重叠。

4. 文本理由与数值结果方向一致。
   - weak 条件后期理由集中在：
     - AI 将重塑劳动市场；
     - 重复性工作被替代；
     - 技能转型不可避免；
     - 个体需要适应技术变化。
   - lifelong strong 条件更常调用：
     - 长期职业经历；
     - 生计位置；
     - 现场判断；
     - 情感劳动；
     - 制度保障；
     - 责任关系。

5. 术语要谨慎。
   - weak 条件更适合写“高分端集中 / 高分端饱和 / 单向端点集中 / 高分端同质化”。
   - 不要直接写成经典双峰 polarization。
   - 如果使用“极化”，应解释这里是“向高分端极端区间集中”，不是传统两极对立。

## 一、选题背景与研究问题

### 1.1 选题背景

#### 1.1.1 LLM 如何成为信息交互的核心入口

过去三年，大语言模型（LLM）经历了爆发式增长。从 ChatGPT 到国内各类 AI 助手，LLM 正深刻改变人们获取信息的方式：

- **搜索场景**：用户越来越多地通过 AI 助手而非传统搜索引擎获取知识
- **日常咨询**：写作建议、观点整理、决策参考均可由 LLM 提供
- **社交补充**：许多人将 AI 对话视为与"智者"交流的替代

这意味着，当人们通过 LLM 获取信息时，LLM 输出的内容将影响用户的认知形成与观点塑造。

#### 1.1.2 RLHF 安全对齐：LLM 的"价值观过滤器"

LLM 的强大能力并非天然而来，需要通过**人类反馈强化学习（Reinforcement Learning from Human Feedback, RLHF）**进行对齐训练。

RLHF 的核心目标是让模型输出符合人类价值观——拒绝有害内容、避免极端言论、倾向于"中性"和"平衡"的表达。这一机制被称为**安全对齐（Safety Alignment）**。

通俗地说：
> RLHF 训练让 LLM 被训练成"不爱说极端的话"、"更愿意表达温和中庸的观点"。

#### 1.1.3 "生成式把关"：RLHF 的隐性社会效应

当数百万人通过 LLM 获取信息时，LLM 的这种"温和化"倾向不会只停留在单次对话中，而会通过**大规模的观点修正**，对整个社会的意见分布产生系统性影响。

我们用**"生成式把关"（Generative Gatekeeping）**来描述这一现象：

```
传统把关（Gatekeeping）：
媒体/平台 → 选择性推送内容 → 影响公众

生成式把关（Generative Gatekeeping）：
LLM → 生成"安全、温和"的内容 → 融入用户认知 → 宏观上压缩观点多样性
```

这类似于：在传统社交媒体中，算法倾向于推送"极端内容"（因为极端内容点击率更高）；而 LLM 则执行相反的逻辑——**它倾向于生成"温和、中庸"的内容**，可能从另一个方向压缩观点多样性。

#### 1.1.4 现有研究的空白

这一现象在传统社会科学研究中尚未被充分探讨，原因在于：

| 研究类型 | 局限性 |
|---------|--------|
| 传播学研究 | 关注传统媒体/算法推荐，缺乏 LLM 介入视角 |
| 社会学研究 | 以人类受试者为主，LLM 作为研究工具的讨论不足 |
| AI 伦理研究 | 侧重规范性讨论，缺乏实证量化研究 |

**本研究的核心价值**：首次从计算社会科学视角，通过大规模 Multi-Agent 社会模拟，对 LLM"生成式把关"的社会效应进行实证量化研究。

### 1.2 核心研究问题

本研究聚焦以下两个科学问题：

**RQ1（描述性）**：当封闭社会意见网络高度依赖具有强"生成式把关"特征的 LLM 进行信息交互时，其宏观社会认知图谱走向"观点均质化"的演化速率与拓扑坍缩特征是什么？

**RQ2（解释性）**：RLHF 安全对齐机制（相较于安全向量切除的对照组）在多大程度上加速了系统方差的收敛，强化了"观点均质化"进程？安全对齐所导致的角色漂移（Persona Drift）是否构成收敛加速的中介机制？

### 1.3 研究意义

本研究旨在从计算社会科学视角揭示 LLM 作为信息中介对公共意见多样性的系统性削弱效应，为理解算法把关机制的社会影响提供实证基础。

## 二、理论框架

### 2.1 学科背景

本研究处于计算社会科学、意见动力学与 LLM 研究的交叉领域：

**意见动力学（Opinion Dynamics）** 旨在从数学上描述群体意见如何通过个体间的交互演化和收敛。经典模型包括：

- **DeGroot 模型（1974）**：个体按固定权重平均化邻居观点，理论上保证共识收敛
- **Hegselmann-Krause (HK) 模型（2002）**：引入"有限置信度"机制，观点相近者交互，更符合真实社会分化现象

**网络科学** 为意见传播提供拓扑结构框架：

- **无标度网络（Scale-free Network）**：真实社交网络普遍呈现幂律度分布，少数高中心度节点（Hub）对信息扩散有不成比例的影响
- **Barabási-Albert (BA) 模型**：通过优先连接机制生成无标度网络，是本研究的拓扑基础

**LLM 安全对齐研究**：

- **RLHF（Reinforcement Learning from Human Feedback）**：通过人类反馈信号调整模型，使其输出符合安全偏好
- **Abliteration（Song et al., 2025）**：一种精确控制技术，通过切除安全对齐方向向量，消除 RLHF 效应而不影响其他能力

### 2.2 核心假设与研究逻辑

**本研究的科学假设**：

- **H1**：LLM 介入的社会意见网络会随交互轮数增加出现观点均质化（方差持续下降）
- **H2**：相较于未对齐模型（abliterated），RLHF 对齐模型（Instruct）会加速观点均质化进程
- **H3**：角色漂移（Persona Drift）是 RLHF 加速均质化的中介机制

**机制链条**：
```
RLHF 安全训练 → 模型被训练"拒绝维持极端立场"
    → 多轮对话中主动软化角色（角色漂移）
    → 观点向中庸收敛
    → 宏观表现为观点均质化加速
```

## 三、研究设计

### 3.1 实验范式：Multi-Agent LLM 社会模拟

本研究采用 **Multi-Agent 社会模拟** 范式：将 LLM 作为"人类代理节点"，赋予初始社会角色，在网络结构约束下进行多轮对话交互，观察宏观社会认知图谱的演化。

**与相关研究的区分**：

- 不同于单 Agent 链式推理（Chain-of-Thought），本研究聚焦多 Agent **网络交互**的涌现效应
- 不同于传统 Agent 系统（任务导向），本研究模拟**意见演化**而非任务完成
- 不同于社会实验（受限于招募成本），本研究通过计算模拟实现大规模可复现实验

### 3.2 网络构建

#### 3.2.1 拓扑选择：BA 无标度网络

**选择理由**：

1. **生态效度**：微博、Twitter、知乎等真实社交平台的网络度分布呈幂律特征，BA 模型可复现这一核心统计性质
2. **理论对标**：Hub 节点在意见传播中的放大效应是无标度网络的标志性特征，与"算法推荐放大热门内容"的现实机制一致
3. **参数灵活**：BA 网络由 m（每新节点连接数）控制稀疏程度，可通过 Phase 0 敏感性分析确定

**网络生成算法（Barabási-Albert, 1999）**：

1. 从 m₀ 个初始全连接节点开始
2. 每个新节点以度优先连接概率 P(i) = k_i / Σk_j 加入网络
3. 重复直至达到 N=200 节点

**参数设定**：

| 参数 | 设定值 | 依据 |
|------|--------|------|
| 节点数 N | 200（正式）/ 20（Phase 0） | 导师建议：真实社会网络规模下限 |
| BA 参数 m | 待 Phase 0 确定（候选 2/3） | 需敏感性分析确认 |
| 每轮激活节点数 | 40（约 20%） | 保证充分交互的同时控制计算成本 |

#### 3.2.2 邻居采样策略：有限注意力机制

**问题**：全连接网络下，Hub 节点需处理近 200 个邻居的历史发言，单次 token 量超 38,000，不现实。

**解决方案**：采用**有限注意力（Bounded Attention）**机制：

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 采样策略 | 度数平方根加权（α=0.5） | Hub 节点发言更易被看到，模拟算法推荐效果 |
| 邻居上限 | 最多 10 个 | 控制 Token 消耗 |
| 记忆窗口 k | 每邻居保留最近 3 轮 | 平衡历史信息与计算成本 |
| Token 估算 | ~2,500 tokens/请求 | RTX 4090 可稳定处理 |

**采样公式**：
$$P(选择邻居_i) = \frac{\sqrt{k_i}}{\sum_{j \in N(v)} \sqrt{k_j}}$$

其中 k_i 为邻居节点度数，N(v) 为当前节点邻居集合。

#### 3.2.3 交互流程：同步批量更新

每轮交互采用**同步更新机制**：

```
第 t 轮：
┌─────────────────────────────────────────────┐
│ 1. 感知阶段                                  │
│    - 所有激活节点读取上一轮（t-1）结束时邻居状态快照  │
│    - 按度数平方根加权采样最多10个邻居              │
│    - 每个邻居保留最近3轮发言，构建Prompt          │
├─────────────────────────────────────────────┤
│ 2. 生成阶段（并发执行）                         │
│    - 40个激活节点并发调用API                    │
│    - LLM生成回复文本 + 自报评分【评分：X】         │
│    - 50字以内，1-10分                          │
├─────────────────────────────────────────────┤
│ 3. 广播阶段（统一写入）                         │
│    - 本轮所有新观点统一写入                      │
│    - 对直接邻居可见，对其他节点不可见              │
│    - 进入第t+1轮                               │
└─────────────────────────────────────────────┘
```

**同步机制的选择依据**：

- **优势**：与 DeGroot、HK 等经典意见动力学模型对标，可复现性强；消除激活顺序隐变量
- **局限**：真实社交媒体（微博、朋友圈）为异步更新，Hub 节点同轮内放大效应更强
- **处理**：在论文局限性部分明确讨论此权衡

### 3.3 Agent 设计

#### 3.3.1 角色设定

每个 Agent 具有两个核心属性：

| 属性 | 描述 | 示例 |
|------|------|------|
| **角色描述** | 系统提示词定义的社会身份 | "25岁激进左翼青年"、"40岁保守派企业主" |
| **初始立场** | 1-10分的正态分布观点评分 | 1=极端反对AI取代劳动力，10=极端支持 |

**角色设计原则**：

- 覆盖政治/经济/社会多维度，增加初始观点异质性
- 两极端（1-2分/9-10分）占比约 20%，中间（4-6分）占比约 50%
- 确保网络A/B两组初始分布一致（固定随机种子）

#### 3.3.2 记忆机制

- **存储结构**：本地 List，按轮次存储历史对话
- **滑窗大小**：k=3（每邻居保留最近3轮发言）
- **Token 控制**：Prompt 估算 ~2,500 tokens（含系统提示）

#### 3.3.3 LLM 选择

| 模型 | 用途 | 来源 |
|------|------|------|
| **Qwen2.5-7B-Instruct** | 网络A（对齐组） | ModelScope |
| **Qwen2.5-7B-Instruct-abliterated** | 网络B（对照组） | HuggingFace 社区版 / FailSpy 自行生成 |

**选择 Qwen2.5 系列的理由**：

1. 中文能力强，适配国内议题（AI取代劳动力）
2. 显存需求适中（7B），RTX 4090 24GB 可运行 fp16
3. 两组架构完全相同（仅安全对齐向量不同），可精确归因

### 3.4 实验分组

| 网络 | 组别 | 模型 | 核心假设 |
|------|------|------|---------|
| **网络 A** | 控制组 | Qwen2.5-7B-Instruct（完整RLHF） | RLHF 安全对齐会加速均质化 |
| **网络 B** | 对照组 | Qwen2.5-7B-Instruct-abliterated（安全向量切除） | 基线均质化速率 |

**设计优势**：

| 对比方案 | 优势 | 劣势 |
|---------|------|------|
| ~~Instruct vs Base~~ | 常规对比 | 差异包含SFT+RLHF+格式，混淆变量过多 |
| **Instruct vs Abliterated** | 精确孤立RLHF效应 | 需额外生成abliterated版本 |
| ~~Instruct（单组）~~ | 简单 | 无法归因，结论弱 |

**分组设计的精确归因逻辑**：
```
网络A - 网络B 的差异 = RLHF安全对齐的独立效应

两组完全相同的部分：
✓ 相同的模型架构（Qwen2.5-7B）
✓ 相同的SFT权重结构
✓ 相同的chat格式
✓ 相同的初始角色设定
✓ 相同的网络拓扑

两组唯一差异：
✗ 网络A有RLHF安全对齐向量，网络B该向量被切除
```

## 四、测量指标

### 4.1 主指标：观点评分时序

每轮记录全体 agent 的自报评分（1-10），计算：

| 指标 | 计算方式 | 解读 |
|------|---------|------|
| **方差时序** | 每轮观点分布方差 Var(S_t) | ↓ = 多样性消失 |
| **均值时序** | 每轮均值 E(S_t) | 是否向5漂移 = 中庸化 |
| **收敛半衰期** | 方差下降至初始值50%所需轮数 | 量化收敛速度 |

**提取方式**：Prompt 末尾强制要求输出 `【评分：X】`，正则解析提取。

### 4.2 验证指标：语义嵌入相似度

- **模型**：`BAAI/bge-large-zh-v1.5`
- **指标**：每轮所有 agent 文本输出的平均两两余弦相似度
- **用途**：与评分方差交叉印证；若两套指标方向一致，结论更可信

**可信度检验**：Spearman 相关系数（自报评分 vs 嵌入向量位置），ρ > 0.6 视为有效。

### 4.3 机制验证指标：角色一致性得分

$$角色一致性得分(t) = cosine( embed(第t轮输出), embed(初始角色描述) )$$

- **预期**：网络A角色一致性随轮次单调下降；网络B保持相对稳定
- **作用**：作为论文机制验证图，解释"Instruct网络收敛更快"的内在路径

### 4.4 宏观网络拓扑指标

| 指标 | 计算方式 | 解读 |
|------|---------|------|
| **模块度 (Modularity)** | Q = (实际边 - 随机期望) / 总边 | → 0 表示多重观点派别消失 |
| **社群数量** | 基于评分分段聚类动态检测 | 观点社群随轮次减少 |

### 4.5 统计方法

主统计方法采用 **LMM 线性混合模型**：

```
方差 ~ 轮次 × 组别 + (1 + 轮次 | run_id)
```

- 固定效应：轮次×组别交互项（检验收敛斜率差异）
- 随机效应：run_id 截距+斜率（处理5次重复间的变异）
- 优势：充分利用50轮×5次=250个数据点，保留完整时序信息

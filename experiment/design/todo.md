## 实验 Pipeline 总览

```
Step 1: 三档议题 probe
Step 2: 人口学画像采样
Step 3: 初始观点分布拟合
Step 4: 零交互基线诊断（Phase 0 前置）
Step 5: Phase 0 敏感性矩阵（m × α × T × Persona × Model）
Step 6: 正式实验（200 × 50 × 5 × 2 模型 × 3 议题）
Step 7: LMM + H1-H5 联合检验 + 中介分析
```

> **阻塞后续**：Step 3、Step 6

  - [ ] 若 CNNIC 六维数据充分 → 六维采样
  - [ ] 若不足 → 退到三维（年龄 × 性别 × 学历）

## Step 4: 零交互基线诊断（优先级：最高）

> **目标**：分离 LLM 内禀坍缩与网络动力学贡献；H1 直接检验
> **前置条件**：Step 1-3 完成
> **阻塞后续**：Step 5、Step 6

- [ ] **4.1 编写零交互基线脚本**
  - [ ] 200 个 agent，0 轮网络交互
  - [ ] 每个 agent 仅输出 Round 0 的初始观点（基于 Step 3 的分布）
  - [ ] 两组模型都跑：Instruct vs abliterated

- [ ] **4.2 测量指标**
  - [ ] **H1 直接检验**：两组输出的 token-level 熵差
  - [ ] 边际侧坍缩量化：Round 0 评分的 SD、均值偏移
  - [ ] BGE 嵌入相似度：200 个 agent 输出的两两余弦相似度
  - [ ] 角色一致性得分（仅 persona 组）

- [ ] **4.3 诊断结论**
  - [ ] 若 Instruct Round 0 已显著坍缩 → 证实 H1，网络动力学是"加速器"
  - [ ] 若 Instruct vs abliterated Round 0 无显著差异 → 重新评估 H1 操作化
